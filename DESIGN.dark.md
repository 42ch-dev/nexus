# Nexus Design System — Dark Theme

<!-- COMPLETENESS_LEVEL: 3 — Production contract, reviewed 2026-09-09; runtime acceptance is separate -->

Graphite companion to [DESIGN.md](DESIGN.md), with exactly the same token paths. The complete typography, spacing, component, focus, motion, logo, accessibility, voice and projection contracts in that file apply here. This is not a separate design system.

Dark values use brighter cobalt interaction on neutral graphite planes. Bright primary/destructive/solid-status fills use `brand-deep-blue` labels, not white. Dark small metadata uses gray-700; scrims remain dark, never inverted gray-1000 washes. Content display is the same offline system sans hierarchy as light, not serif.

## Contrast

Design-time sRGB arithmetic: gray-1000 on background-100 16.15:1; gray-700 on background-300 6.78:1; gray-600 on background-300 4.98:1; blue-700 on background-300 6.52:1; brand-deep-blue on blue-700/800/900 6.81/8.08/9.54:1. These are token calculations, not rendered QA. Actual alpha/state combinations require browser evidence.

## Logo Usage

Frozen installed SVG/PNG pigments and desktop icons are unchanged. See [light contract asset boundary](DESIGN.md#logo-usage): live NexusMark uses currentColor cobalt; historical mood marks and baked gradients are labeled asset references, not application themes. Keep square plates separate from plain wide marks; 14px compact, 20px shell plate, 24px general mark, 25% clear space.

## Elevation and Motion

Dark elevation values are explicitly in frontmatter; they separate planes without glow. Durations and easings match light. Reduced motion is immediate; comparison frames honor the media preference independently while using the same runtime CSS pipeline.
