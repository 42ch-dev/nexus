# Self-Hosted OFL Font Wiring Pattern

**Track**: Knowledge (durable guidance distilled from V1.121 v0.4 display typography tier implementation).

## Context

V1.121 needed a literary serif (Source Serif 4) as the content-voice typeface. Nexus is a local-first product — no webfont CDN dependency. The font also had to respect the `@42ch/nexus-ui` bundler-agnostic asset boundary (see [bundler-agnostic-component-library-assets.md](bundler-agnostic-component-library-assets.md)): a tsup-built React component library cannot import `.woff2` binaries in source.

The solution spans five layers: canonical provenance → package boundary → app vendoring → `@font-face` in shared CSS → preload in each app. A measurable bundle gate ensures the pattern doesn't silently bloat the shipped bundle.

## Guidance (the pattern)

### Step 1 — Acquire and prove

- Acquire the OFL font via `@fontsource/<family>` npm package (or direct download from the foundry's GitHub release).
- Verify the OFL-1.1 license is present and allows self-hosting, modification, and sub-licensing (all standard OFL fonts do).

### Step 2 — Canonical provenance + license

- Place the full font binary (or the canonical subset source) in `packages/nexus-ui/assets/fonts/<family>/`.
- Include the OFL-1.1 license file alongside (e.g., `OFL.txt`).
- Track binary files via Git LFS if they exceed the repo's binary threshold (`.gitattributes` — `packages/nexus-ui/assets/fonts/** filter=lfs diff=lfs merge=lfs`).
- This is the **canonical provenance** — the single source of truth for the font binary. It matches the existing `packages/nexus-ui/assets/logos/` precedent for LFS-tracked source assets.

### Step 3 — App vendoring (bundler boundary)

Each consuming app **must not** import font binaries from package source. `packages/nexus-ui/AGENTS.md` forbids binary asset imports from component source, and deep-imports of `@42ch/nexus-ui/src/*|assets/*` are forbidden. Instead:

- Generate subset `.woff2` files (Latin + common punctuation + figures, static weight ramps) from the canonical file.
- Vendor each subset into each app's `public/fonts/<family>/` directory.
- Include a `PROVENANCE.md` file in each app's `public/fonts/<family>/` pointing back to the package canonical path:

```markdown
# Font provenance

These files are a subset of the Source Serif 4 OFL typeface.
Canonical binary + OFL-1.1 license:
  packages/nexus-ui/assets/fonts/source-serif-4/
Regeneration step:
  pnpm exec glyphhanger --subset=... --formats=woff2 ...
```

- The subset is regenerated by a documented copy step — no runtime cross-package binary import.

### Step 4 — `@font-face` declarations + token variable

- `@font-face` declarations live in `tooling/design-tokens/src/tokens.css` (shared CSS, both themes where identical).
- Each weight gets its own `@font-face` block with `font-display: swap`.
- The `--font-<role>` CSS variable (e.g. `--font-display`) is defined in the same file, pointing to the font family name.
- The URL path is relative to the app's served root: `url('/fonts/source-serif-4/source-serif-4-latin-400-normal.woff2')`.

```css
@font-face {
  font-family: 'Source Serif 4';
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url('/fonts/source-serif-4/source-serif-4-latin-400-normal.woff2') format('woff2');
  unicode-range: U+0000-00FF, U+0131, …;
}
```

### Step 5 — Preload

- Add `<link rel="preload" as="font" type="font/woff2" crossorigin>` for the primary weight (400) in each app's `index.html`.
- Only preload the most-used weight — additional weights are loaded on demand via `@font-face` `font-display: swap`.

### Step 6 — Bundle gate (measurable cost)

- **Gate**: measure gzipped `.woff2` size per weight. Set a threshold (V1.121: ≤ 80 KB gz/weight).
- If the measured size exceeds the gate, fall back to the system-serif stack (e.g., `Georgia, 'Times New Roman', ui-serif, serif`) and record a Durable Roadmap entry on the plan for a future iteration (bundle optimization, narrower subset, or alternative family).
- **V1.121 measurement**: Source Serif 4 Latin subset measured 19.7 KB gz (400 weight) / 21.1 KB gz (600 weight) — far under the 80 KB gate.

### Step 7 — Tailwind preset wiring

- Add `fontFamily.display` in `tooling/design-tokens/tailwind.preset.ts` pointing to `var(--font-display)`.
- Add `fontSize.display-*` entries referencing the `--text-display-*` metric CSS vars.
- Register `font-display` in the `tailwind-merge` `font-family` class group at `packages/nexus-ui/src/lib/cn.ts` (prevents `font-display` from being silently stripped).

## Why This Matters

- **Local-first principle**: no webfont CDN dependency — the app works offline, no third-party DNS/network, no tracking.
- **Bundler-agnostic package boundary**: fonts don't break the `@42ch/nexus-ui` tsup build (no `.woff2` import in source). Each app vendors its own copy, which is the standard Vite pattern for static assets.
- **Measurable cost gate**: the bundle delta per weight is visible and gated, preventing silent bloat. 80 KB gz/weight is generous for a Latin subset — CJK subsets would be larger and may need separate tuning.
- **Swap + preload**: `font-display: swap` prevents invisible text during load; preload ensures the primary weight is fetched early. The system-serif fallback stack renders instantly if the font is unavailable.

## When to Apply

- Adding a display tier typeface (e.g., Source Serif 4 — done in V1.121).
- Adding a mono companion typeface for code/terminal surfaces (future candidate).
- Adding a CJK serif companion for zh-CN content titles (V1.122 candidate — expect larger subset size, potentially exceeding the 80 KB gate; may need per-script tuning).
- Any future self-hosted font that must be served from a local-first, bundler-agnostic workspace.

## Do NOT

- Import `.woff2` or `.ttf` binaries in `packages/nexus-ui/src/` — the tsup build cannot resolve them and the bundler-agnostic contract forbids it.
- Point `@font-face` `src` at a CDN — defeats the local-first principle.
- Skip the preload tag — the font will be discovered late, causing a flash of invisible text (FOIT) or flash of unstyled text (FOUT).
- Skip the bundle gate — a 200 KB+ weight silently adds critical network cost to the first load.
- Use a single giant weight file (e.g., variable font axis) without subsetting — the Latin subset of a variable font is typically 100–200 KB; gating catches the excess.
- Hardcode font URLs in app-local CSS — `@font-face` must be in the shared `tokens.css` so all surfaces consume the same declarations.
