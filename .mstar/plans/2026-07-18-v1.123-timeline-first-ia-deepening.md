# P3 — Timeline-First IA Deepening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd` (recommended). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Deepen "Timeline 一定要突出" from a V1.122 route default to structural prominence across the app's IA: add a global Timeline entry (cross-World overview) to primary nav; visually distinguish Timeline in Canvas shell nav; surface Timeline activity on Worlds list and Works list; enable cross-surface Timeline navigation (Work Timeline Moment ↔ bound World Timeline Narrative).

> **Terminology note:** "Narrative" here refers to the Timeline layer (event-level), distinct from prose-craft narrative writing. "Moment" refers to the Timeline layer (scene/beat-precise), distinct from Moment Context Assembly. See CONCEPTS.md § Narrative / § Moment.

**Architecture:** Frontend IA refactor. Adds global Timeline view (`/timeline` or equivalent primary-nav entry) composing recent Timeline activity across Worlds; Canvas shell nav visual prominence for Timeline (accent color + ordering + activity badge); Worlds list + Works list surfaces Timeline activity data (last-edited layer, Brief/Narrative/Moment counts); cross-surface navigation between Work Timeline Moment and bound World Timeline Narrative (and reverse). No backend changes required if P0/P1/P2 expose the needed data via existing endpoints; if not, P3 may degrade to "recent Timeline activity list" (honest scope cut documented).

**Tech Stack:** TypeScript, React, `apps/web` (Vite SPA), `packages/nexus-ui`, vitest. Rust/daemon unchanged unless P0 architect lock requires otherwise.

### Data composition (architect LOCKED in `three-layer-architecture.md` §5 + §8)

- **Global Timeline view (AC-V1123-16)** — client-side composition from existing per-World data. Two paths:
  - **Preferred (lower churn):** for each visible World (cap N=5–10 most-recent by default), fetch `GET /v1/daemon/worlds/{world_id}/kb/graph` (V1.73) and aggregate `entities[block_type=era]` + `entities[block_type=event]` into a unified recent-activity list. No new composite endpoint.
  - **Fallback (if N+1 fetch cost is prohibitive):** degrade to a "Worlds list + last-edited timestamp" rendering — honest empty-state for the per-layer counts. Document the degradation in completion report + register a residual. Do NOT silently degrade.
- **Canvas shell Timeline prominence (AC-V1123-17)** — visual only; data already exists. Add Timeline accent token (`--color-canvas-timeline-accent`), Timeline-first ordering in shell nav, activity badge (recent-edit indicator from existing `updated_at` on KeyBlock entities).
- **Worlds/Works list Timeline activity (AC-V1123-17)** — derive from existing read models:
  - For Worlds list: count `block_type=era` (Brief) + `block_type=event` (Narrative) entities per World from `WorldKbGraphResponse`; surface as "Brief: N eras · Narrative: M events · last-edited: <ts>".
  - For Works list: count `WorkOutline.timeline_events[]` per Work from `GET /v1/daemon/works/{work_id}/outline`; surface as "Narrative: N events · last-edited: <ts>". Scene/Beat counts deferred to V1.124+ (`DF-V1123-MOMENT-WIRE`).
  - If list endpoint performance is unacceptable with per-item outline fetches, degrade to "last-edited time" only — honest scope cut documented in completion report.
- **Cross-surface navigation (AC-V1123-18)** — bound World Timeline Narrative ↔ Work Timeline Moment requires data linking:
  - Work Timeline Narrative event (`WorkOutline.timeline_events[].event_id`) binds to World Timeline Narrative event via the Work's `world_id` + an optional event-binding field. P3 may use `WorkOutline.timeline_events[].realizes_chapter_id` (chapter-level binding, already in V1.72 wire) as the join key when an event is chapter-anchored; for direct World-event binding, P3 may rely on heuristic matching (canonical_name overlap) — honest scope cut if heuristic is unreliable.
  - "View on World Timeline" affordance navigates to `/worlds/:worldId/timeline?layer=narrative&event=:eventId` (event-id highlight optional — see P1).
  - "View in Work Timeline" affordance navigates to `/works/:workId/timeline?layer=narrative` (Moment layer one click away).
  - If binding is missing or unreliable, P3 hides the affordance or shows "no bound World event / Work realization" hint copy — honest scope cut per product spec §5.3.

### Cross-surface navigation URL contract (LOCKED — consistent with P1 + P2 + P4)

- World Timeline route: `/worlds/:worldId/timeline?layer=brief|narrative&event=:eventId` (P1 owns `?layer=`; P3 adds optional `&event=`).
- Work Timeline route: `/works/:workId/timeline?layer=narrative|moment` (P2 owns `?layer=`; P3 reads for cross-surface jump).
- Invalid `?layer=` values are ignored per the layer-state persistence contract in `canvas-strategy-surface.md` §3.3.3 (Moment on World → ignore; Brief on Work → ignore).
