## Problem Statement

Setup/Settings agent picker leaks ACP jargon, fails to open outbound links in the
system browser on desktop, ignores registry icon/website fields, and surfaces
ACP wrappers in the default grid instead of native Claude/Codex.

## Scope

### In scope

- De-ACP copy; system browser opener for Install/Docs
- Card: name, description, website, icon (+ registry SVG fallback)
- Repo config: install URL whitelist + field overrides
- Claude/Codex **Native Adapters** in default grid; hide ACP wrappers from default
- More Agents: installed first

### Not in scope

- `~/.nexus42` user override layer; CDN mirror
