## Problem Statement

V1.135 restored create to the **shell sidebar** (placement win), but the 功能区 is still two dashed **Create cards** (`CreateCardButton` ×2) that open dialogs. Author wants an **inline create zone**: local **World | Work tabs** + title field + submit — not card buttons. Content remains browse/empty (“从侧边栏创建”).

**User value:** Faster create flow — tab, type title, submit in sidebar; content stays clearly browse-only.

**Supersedes:** Card-button hub UX from V1.135 P0 wiring; does **not** revert V1.135 sidebar placement (still `panelContent`, not content dual-pane).

## Goal

1. Replace dual `CreateCardButton` hub path with **tabbed inline create** in `ShellSidebarChrome.panelContent`.
2. Content = list/empty only (no create cards in content).
3. Studio fixture first (single theme follow global toggle — no Light\|Dark matrix).
4. Update `workspace-parent-shell-ia` knowledge at implement (not Phase 1).
