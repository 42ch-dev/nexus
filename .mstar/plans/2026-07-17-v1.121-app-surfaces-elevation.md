- **Problem:** generic shell, no first-impression brand moment, utilitarian states, highest arbitrary-value heat in pages (`findings-page.tsx` etc.).
- **Scope:** shell chrome; setup wizard + connection setup + splash; Works/Worlds/Chapters/Sessions/Schedule/Modules/Findings/Memory/Strategies/Settings/NotFound; empty/error/loading states; arbitrary-value sweep; **register** `canvas-node-width-*` tokens for P3 (no canvas visual change).

- **Draft DoD:** AC-P2-1…7.

### Clarify (locked — PM, autonomous)

- **Voice split:** creative-entity titles (works, worlds, chapters on list pages) → `display-24/20` serif; all chrome (nav/tabs/headers-as-chrome/tables/badges/buttons/labels) → sans. Page `h1` on entity-detail-like pages may be serif; section headers stay sans. Rule recorded in DESIGN.md body; greppable both directions.
- **Setup wizard:** serif welcome headline + ambient card on tinted backdrop; V1.96 geometry (`wizard-max-width` etc.) unchanged; step indicator tokens reused; **flows/step order/success criteria unchanged**.
- **Sidebar:** active item = active bar `blue-700` + `gray-alpha-100` wash (existing tokens); group collapsibles get 120ms state transitions; brand mark per `shell-nav`.
- **Command palette:** `bg-scrim` + `elevation-4` + refined item states; V1.111 ARIA behavior untouched.
- **Canvas node widths:** register the `canvas-node-width-*` family in DESIGN.md under **`components.canvas.node-width.<role>`** per the contract authored in P0 spec T5 — 5 grep-verified values: strategy-root `260px` (`strategy-nodes.tsx:133`), strategy-primary `140px` (`:174`), strategy-secondary `150px` (`:190`), outline-scene-beat `160px` (`outline-canvas/scene-beat-nodes.tsx:72,120`), default `176px` (`presentational/node-chrome-shell.tsx:94` NodeChromeShell default). Project to tokens.css + tailwind preset `minWidth`; fix the utility prefix as `min-w-canvas-node-<role>` here so P3 consumes one name; add the family to the twMerge `min-w` group at `packages/nexus-ui/src/lib/cn.ts` (per P0 T7). **Registration only — no canvas visual adoption in P2** (P3 applies).
- **States editorial polish:** serif headline allowed for EmptyState (content voice); locale **strings** unchanged; sentence-case helpers + first action retained.
