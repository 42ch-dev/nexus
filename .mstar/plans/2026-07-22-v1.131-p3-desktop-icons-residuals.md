## Architecture lock (architect Seat 2)

- **Source chain:** canonical input is `packages/nexus-ui/assets/logos/logo-primary.svg`; `compose-app-icon.mjs` is the only vector→PNG composer. Commit only `source-1024.png` (LFS) and `app-icon-preview-256.png` as source/provenance outputs; platform icon files remain generated.
- **Commands:** use `pnpm --filter desktop run icons:compose` and `pnpm --filter desktop run icons:generate` because root has no `icons:*` aliases. `icons:generate` recomposes before `tauri icon`; the explicit compose run is a review checkpoint, not a second pipeline.
- **Determinism:** record SHA-256 for both source rasters before and after. If either changes, commit source+preview atomically; if neither changes, record the match and make no asset-only commit.
- **Runtime truth:** preview review is necessary but not sufficient. Build/reinstall the `.app`, invalidate Dock cache per README, and inspect the actual Dock tile; OS mask/cache behavior is the acceptance surface.
- **Residual ownership:** P3 archives/re-defers ledger rows only. It never edits P0/P1/P2 UI to manufacture closure. `DF-V1130-*` feature rows are must-ship and cannot be re-deferred here.
