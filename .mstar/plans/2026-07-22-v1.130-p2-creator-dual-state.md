## Architecture lock

- **Create World contract:** add generated `CreateWorldRequest { title: string }` and `CreateWorldResponse { world_id: string, status: string }` for `POST /v1/daemon/worlds`. Title is trimmed and validated (1–200 chars). The daemon reads the active creator; clients never send ownership.
- **Server defaults:** derive an ASCII kebab slug from title, using `world` when normalization yields empty, with deterministic `-2`, `-3`, … collision suffixes inside the active creator scope; default `visibility=private`, `time_policy=manual`, `status=active`. Delegate persistence to `nexus_local_db::narrative_write::create_world`; return `201`.
- **Client boundary:** promote `createWorld(request)` onto `NexusClient` and `BrowserClient`; use a query mutation that invalidates World/Timeline list keys. On success navigate to `/worlds/{world_id}/timeline`. No desktop-only IPC is needed because desktop data traffic already uses the daemon HTTP client.
- **Wire delivery:** schema files, generated Rust/TypeScript, drift registration, daemon request/response types, route tests, client adapter tests, and UI mutation ship together. No handwritten parallel DTO.
- **Chat floor:** show the newest 12 already-available local messages in chronological order. The input row is visible but disabled with honest V1.131 copy. If no typed history source exists, show an empty-history state; do not add a Chat endpoint in this plan. Streaming, send, optimistic echo, tool-call rendering, and ACP orchestration are excluded.
- **UI placement:** Studio fixtures use props-driven creator chrome via `@web-layout/*`; App pages own queries, mutations, selection, and navigation. No templates.
