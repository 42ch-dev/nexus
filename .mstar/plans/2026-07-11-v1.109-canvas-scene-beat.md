# P0 — Canvas Scene/Beat Expansion (C2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd`. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Extend the Outline canvas graph from Volume/Chapter to **Scene/Beat** node granularity so authors can see and steer scene-level structure spatially.

**Architecture:** Scene/Beat nodes render as React Flow child nodes inside Chapter parent nodes (`parentId` + `extent: "parent"`), projected from **fixture-injected scene/beat payloads** (the outline model carries no scene/beat data today — §5.2 Q1 evidence). The RF projection (`rf-projection.ts`) gains Scene/Beat node types with Scene→Beat nesting (Beat's `parentId` = Scene node id). A new Scene/Beat inspector (read-only) drives from node selection. The alt list view extends with Scene/Beat rows. DESIGN.md gains `canvas-outline-scene-*` / `canvas-outline-beat-*` tokens. **Architect-locked extract:** `useOutlineCanvasGraph()` (projection + RF state + selection sync) is pulled out of `outline-canvas.tsx` in Task 1 so Scene/Beat selection wiring stays clean and R-V1108P0QC1-S001 + R-V1108P1QC1-S002 close as side effects.

**Tech Stack:** `@xyflow/react` (React Flow v12), TypeScript, `@42ch/nexus-contracts`, Tailwind + DESIGN.md tokens, Vitest + React Testing Library.

**Execution:** mstar-sdd

**Primary spec:** `.mstar/iterations/v1.109/specs/canvas-scene-beat.md` (§5.1 product-complete — FB-C2-000..004 expanded)

## Architectural context

**Current state (V1.108 C1):**
- `rf-projection.ts` projects Volume/Chapter/Timeline nodes in a 3-lane grid
- `outline-nodes.tsx` renders Volume/Chapter/Timeline custom node types
- `use-outline-data.ts` fetches `WorkOutline` + `ChapterSummary[]`
- Alt view (`outline-alt-view.tsx`) has chapter list + timeline event list
- `canvas-outline-*` DESIGN tokens exist for volume/chapter/timeline

**Target state (C2):**
- Scene/Beat nodes as RF children of Chapter parent nodes (fixture-driven; honest empty chrome when no fixture data)
- Scene/Beat inspector (read-only display; write deferred — no wire change)
- Alt view Scene/Beat rows nested under chapters
- `canvas-outline-scene-*` / `canvas-outline-beat-*` DESIGN tokens
- `useOutlineCanvasGraph()` extract (R-V1108P0QC1-S001 closed; unblocks R-V1108P1QC1-S002)

**Architect lock (§5.2):** The outline model has **no scene/beat data** (`work-outline.schema.json`, `chapter-summary.schema.json`, `chapter-outline.schema.json`, `WorkChapterRecord`). Scene/Beat projection is **fixture-driven**: Design Studio / test fixtures inject scene/beat payloads at the UI projection layer. `wire_contracts_changed: false` holds because the projection emits zero scene/beat children when no fixture data is present. Hierarchy is Scene→Beat (Beat's `parentId` = Scene node id), matching master §3.4.
