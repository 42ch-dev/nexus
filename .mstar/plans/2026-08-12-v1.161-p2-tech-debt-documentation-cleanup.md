## 5. Tasks

### T1: Archive closed residuals + refresh tech_debt_summary

**In scope files:**

- `.mstar/status.json` (`residual_findings`, `metadata.tech_debt_summary`)
- `.mstar/archived/residuals/<plan-id>.json` (create or merge)

**Procedure (SSOT):** `.mstar/knowledge/conventions/profile-b-residual-archival-procedure.md` + sweep playbook open-filter.

1. Re-read `status.json`; list closed/resolved vs open with the inclusive open-filter from the sweep playbook.
2. For each closed row: ensure `closure_note` (ND-A2 enum or pre-existing note) + timestamps; set `archived_at`.
3. **Move** entry to `.mstar/archived/residuals/<plan-id>.json` (read existing array → append → write). Remove from hot `residual_findings[plan_id]`; drop empty plan keys only if no open rows remain for that key; **keep** plan keys that still hold open rows (mixed-severity rule).
4. Recompute `metadata.tech_debt_summary`:
   - `updated_at`: execute day (`YYYY-MM-DD`)
   - `total_open`, `by_severity`, `by_target`, `by_plan` from **open rows only**
   - Assert internal sums match `total_open`

**STOP if:** a “closed” row lacks credible closure evidence and looks mistakenly closed — escalate; do not invent closure. If archive file shape is not a JSON array, STOP and fix shape before merge.

**Done when:** AC-P2-1..4 hold.
