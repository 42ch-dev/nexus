**Goal (user value):** An author with a reachable daemon can create a Profile from the footer and see it stick; when create truly cannot reach the daemon, the dialog names the real cause and offers one honest next step — never the multi-cause generic blob.

**Architecture:** Add the missing `POST /v1/daemon/creators` daemon route (mirror the V1.119 `patch_creator` pool-attach pattern), introduce a `TransportErrorKind` enum on `NexusClientError` in the web client, and rebuild `CreateCreatorDialog` with an inline classified error region + CTAs.

**Tech Stack:** Rust + axum (daemon), React 18 + TypeScript + Vitest (web).

**Execution:** mstar-sdd (multi-task)

## Architect lock (Seat 2) — POST /v1/daemon/creators + classification

> Locked 2026-07-21. See `.mstar/iterations/v1.129/specs/profile-create-reliability.md` § Interfaces + § Risks for full rationale.

1. **Wire contract:** `POST /v1/daemon/creators` returns `CreatorDetail` (reuse existing struct). Response shape: `{ creator_id, handle: null, display_name, has_api_key: false, has_cached_token: false, is_active: false }`.
2. **Route tier:** Tier-1 (API key) only — add `.post(handlers::creators::create_creator)` to the existing `tier1_routes` `.route("/v1/daemon/creators", ...)` line. Do NOT register a duplicate route or gate on active creator.
3. **Pool-attach pattern:** Mirror `patch_creator` at `creators.rs:533-541`. Lazily attach via `state.ensure_creator_pool()` on entry when `active_creator_id` is set in config but pool is not yet open. If no creator is active and pool is absent, attempt insert — return `Internal` on DB schema absence.
4. **TransportErrorKind:** Instance field `kind?: TransportErrorKind` on `NexusClientError` (`errors.ts:34-45`). Not a discriminated union of subclasses.
5. **Classification algorithm (in `BrowserClient.request()` catch block):** (1) `baseUrl === ''` → `daemon_down`, (2) TypeError → `network`, (3) AbortError → `timeout`, (4) TLS best-effort via substring match → `tls` else fallback to `network`, (5) response 200 + `Content-Type: text/html` → `http_fallback` (inject before `!response.ok` check), (6) else → `unknown`.
6. **Tauri parity:** `TauriClient extends BrowserClient` — shares the same `request()` throw path. No separate classification needed.
7. **TLS fail-open:** Browser hides precise cert failure reason. `tls` is best-effort; fall back to `network` when ambiguous. Copy must not over-claim certificate rejection.
8. **Task order:** T1 (RCA) → T2 (route) → T3 (classification) → T4 (dialog) → T5 (regression). Serial.

## Global Constraints

- Error envelope: every daemon error response uses `nexus_daemon_runtime::api::errors::NexusApiError` — no ad-hoc JSON (`crates/nexus-daemon-runtime/AGENTS.md`).
- sqlx: compile-time macros (`sqlx::query!` / `query_as!`); regenerate `.sqlx/` after schema or query changes (`cargo sqlx prepare --workspace --all -- --all-targets`).
- Pool-attach: existing creator handlers attach the workspace pool inside the handler (cf. `patch_creator` V1.119 fix). The new `create_creator` handler must do the same; existence checks run **before** any lock acquire.
- TypeScript strict: no `any` for wire shapes; use generated `@42ch/nexus-contracts` types.
- i18n: every new user-facing web string lives in `apps/web/src/locales/{en,zh-CN}/` from day one. New strings follow the per-namespace dot-separated convention.
- Voice & Content: Title Case for titles/buttons, sentence case for helpers/errors, verb-only CTAs (`Retry`, `Open Connection Settings`).
- Studio-first does **not** apply to P0 — the dialog is product-state coupled (mutation, connection config) and stays in `apps/web/src/components/layout/`. The shared presentational primitive extracted in P1 follows Studio-first.
