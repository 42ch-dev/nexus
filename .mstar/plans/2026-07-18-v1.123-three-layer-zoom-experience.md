# P4 — Three-Layer Zoom Experience Differentiation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd` (recommended). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Differentiate the feel of Brief, Narrative, and Moment layers so each has its own layout, density, visual language, and zoom interaction — honoring caller's "三层不一样的感受" mandate. Implement semantic zoom (not just viewport zoom) for Brief↔Narrative (World Timeline) and Narrative↔Moment (Work Timeline) transitions; layer-state persistence across surface switches; per-layer honest empty-state copy.

> **Terminology note:** "Narrative" here refers to the Timeline layer (event-level), distinct from prose-craft narrative writing. "Moment" refers to the Timeline layer (scene/beat-precise), distinct from Moment Context Assembly. See CONCEPTS.md § Narrative / § Moment.

**Architecture:** Frontend UX refinement across V1.123 P1 (World Timeline Brief+Narrative) and P2 (Work Timeline Narrative+Moment) surfaces. Per-layer layout engines (Brief = horizontal era sweep; Narrative = balanced event + edges; Moment = vertical scene-stack); semantic zoom transitions (animated layer swap, not viewport zoom); layer breadcrumbs; layer-state persistence (switching surface and back preserves layer); per-layer empty-state copy in i18n. Reuses V1.121 design tokens + V1.114 `useCanvasSurface()` composition hook; new layer-feel tokens registered in DESIGN.md / tokens.css as needed.

**Tech Stack:** TypeScript, React, `@xyflow/react` (React Flow), `@dagrejs/dagre`, Framer Motion (if animation; or CSS transitions), `apps/web` (Vite SPA), `packages/nexus-ui`, vitest. Rust/daemon unchanged.

### Semantic zoom feasibility (architect confirms 0.55–0.70 band is feasible)

**Architect verdict: the 0.55–0.70 band proposed in `layer-feel-differentiation.md` §3.2 is feasible against React Flow viewport semantics.** Implementation discipline:

- React Flow exposes continuous viewport zoom via `useViewport()` / `onViewportChange` hooks (`@xyflow/react` v12+). Default viewport zoom is `1.0`; the surface can read the current zoom value and dispatch a layer swap when thresholds are crossed.
- The `useSemanticZoom()` hook (P4 Task 3) reads viewport zoom and emits a discrete `layer-switch` event when:
  - World Timeline: zoom-in past `0.70 × fit-all-Brief-content` scale → swap Brief → Narrative; zoom-out past `0.55 × fit-all-Brief-content` scale → swap Narrative → Brief.
  - Work Timeline: zoom-in past `0.70 × fit-all-Narrative-content` scale → swap Narrative → Moment; zoom-out past `0.55 × fit-all-Narrative-content` scale → swap Moment → Narrative.
- **Hysteresis band (0.55–0.70)** prevents flicker at the threshold: a swap requires clear overshoot past the opposing boundary. The 0.15-unit hysteresis band is sufficient per React Flow's continuous wheel-zoom granularity.
- **If continuous zoom fights discrete swap** (e.g., wheel-zoom feels janky), P4 MAY ship **explicit-only switcher first** with semantic zoom as a P4-later subtask. Document the deferral in completion report + register a residual; AC-V1123-21 allows documented deferral.
- **Explicit switcher is the primary affordance**; semantic zoom is the additive convenience. The layer switcher segmented control MUST always be present (Brief | Narrative on World; Narrative | Moment on Work) so keyboard / AT / no-wheel users can switch layers without zoom.

### Semantic zoom (LOCKED in `layer-feel-differentiation.md` §3 — feasibility confirmed above)

- Brief↔Narrative zoom on World Timeline: zoom-out past Brief threshold → switches to Brief; zoom-in past Narrative threshold → switches to Narrative. Animated transition (Framer Motion `AnimatePresence` or CSS transition) between layer node sets.
- Narrative↔Moment zoom on Work Timeline: same pattern.
- **NOT viewport zoom** — React Flow's default zoom is preserved per layer, but layer swap is a discrete semantic transition, not a continuous viewport zoom.
- Layer breadcrumbs in canvas header: `Brief > Narrative` (World) or `Narrative > Moment` (Work); clicking a breadcrumb switches layer.
