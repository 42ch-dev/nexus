# P2 — Work Timeline Narrative+Moment Dual-Layer Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd` (recommended). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a new peer `CanvasSurfaceKind = "work-timeline"` surface that projects Work-scoped Narrative layer (Work-realized events) and Moment layer (scene/beat precision, manuscript-anchored), reachable as a peer from Work Canvas shell, while preserving Work-entry default to Outline.

> **Terminology note:** "Narrative" here refers to the Timeline layer (event-level), distinct from prose-craft narrative writing. "Moment" refers to the Timeline layer (scene/beat-precise), distinct from Moment Context Assembly (session context packing). See CONCEPTS.md § Narrative / § Moment.

**Architecture:** Frontend + backend additive extension. New `WorkTimelineCanvasAdapter` (in `apps/web/src/components/canvas/work-timeline-canvas/`) projects Narrative layer (Work-scoped events from `timeline.patch_event` data + bound World events at Work resolution per architect lock) and Moment layer (scene/beat precision per architect lock — likely reuse V1.108 `OutlineSceneNodeData`/`OutlineBeatNodeData` or extend timeline-event with `event_type: "moment"`). Work Timeline is a fourth peer surface from Work Canvas shell (alongside Outline, Strategy, World KB); Work entry stays Outline. Canvas header has Narrative↔Moment layer switcher; default Moment layer when scene/beat data exists, else Narrative fallback.

**Tech Stack:** TypeScript, React, `@xyflow/react` (React Flow), `@dagrejs/dagre`, `apps/web` (Vite SPA), `packages/nexus-ui`, vitest. Rust/daemon changes per architect lock.

### Adapter contract (architect LOCKED in `three-layer-architecture.md` §7)

```ts
// apps/web/src/components/canvas/work-timeline-canvas/work-timeline-canvas-adapter.tsx (NEW — V1.123 P2)

import type { MutableRefObject } from 'react';
import type { Edge, Node } from '@xyflow/react';
import type { CanvasSurfaceAdapter } from '../canvas-surface-adapter';
import type { WorkOutline } from '@42ch/nexus-contracts';

type WorkTimelineGraph = WorkOutline;   // single source — no wrapper, no join
type WorkTimelineLayer = 'narrative' | 'moment';

interface WorkTimelineNodeData {
  [key: string]: unknown;
  workId: string;
  nodeKind: 'event' | 'scene' | 'beat';
  nodeId: string;
  label: string;
  description?: string;
  realizesChapterId?: number;
  manuscriptAnchor?: { chapterId: number; sceneId?: string; beatId?: string };
}

type WorkTimelineEdgeData = {
  relation: 'realizes_event' | 'foreshadows';
  sourceEventId?: string;
  targetEventId?: string;
};

interface WorkTimelineCanvasAdapterContext {
  workId: string;
  worldId?: string;     // optional — for P3 cross-surface navigation
  /** Read-only hand-off — Moment + Narrative both route edits through Outline. */
  onEditInOutline?: (node: Node<WorkTimelineNodeData>) => void;
  /** P3 cross-surface navigation hand-off — fired on "View on World Timeline" click. */
  onViewOnWorldTimeline?: (node: Node<WorkTimelineNodeData>) => void;
}

interface WorkTimelineLayerAdapter
  extends CanvasSurfaceAdapter<WorkTimelineGraph, WorkTimelineNodeData, WorkTimelineEdgeData> {
  surfaceKind: 'work-timeline';
  /** Default layer (architect LOCKED §7.3 — Narrative with Moment one click away). */
  defaultLayer: 'narrative';
  projectGraphForLayer(
    graph: WorkTimelineGraph,
    layer: WorkTimelineLayer,
  ): { nodes: Node<WorkTimelineNodeData>[]; edges: Edge<WorkTimelineEdgeData>[] };
  /** Inherited from V1.114 CanvasSurfaceAdapter — MUST delegate to active layer. */
  projectGraph(graph: WorkTimelineGraph): { nodes; edges };
}

declare function createWorkTimelineCanvasAdapter(
  ctxRef: MutableRefObject<WorkTimelineCanvasAdapterContext>,
): WorkTimelineLayerAdapter;
```

**Architect UX-risk override (LOCKED §7.3):** `defaultLayer: 'narrative'` — NOT Moment. The product spec §4.3 preference was "Moment when Scene/Beat data exists"; the architect overrides because the V1.72 `WorkOutline` wire has no Scene/Beat data today (Moment-default would surface persistent empty-state in nearly all real Works). The product spec §4.3 explicitly authorized this fallback with documentation in P2. Moment is one click away via the layer switcher; Work entry still defaults to Outline (V1.118 unchanged). When the WorkOutline wire extends to expose scenes/beats (V1.124+), the default may flip to Moment.
