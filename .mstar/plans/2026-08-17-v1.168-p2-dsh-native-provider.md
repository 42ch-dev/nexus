# Add dsh-native Provider (v1.168 P2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd`. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Authors who already run DeepSeek Harness locally can harness it as `dsh-native` the same way they harness `claude-native` / `codex-native` — bring-your-own runtime, skip-if-missing, no Nexus install.

**Architecture:** New `DshNativeProvider` in `providers/native_cli/dsh.rs`. SDK is a pure client (spawns BYO runtime). Discovery: PATH `dsh-jsonrpc-agent` or `DSH_RUNTIME_BIN`. Boot registers when found. No ACP twin, no `NATIVE_PREFERRED_FAMILIES` row. Surface is locked by AR-2: high-level `DeepSeekHarness` + `Session::run` (one harness per provider session, lazy start, `close()` on shutdown); same `ProviderAdapter` + PD-3 decode contract + one terminal event per turn. Capabilities are the AR-6 documented narrower descriptor (`streaming: false`, `cancellation: false`, `session_restore: true`). Surfacing is the existing native catalog/scan — no new Setup chrome.

**Tech Stack:** `deepseek-harness-sdk` crates.io exact pin; `nexus-agent-host`; `nexus-daemon-runtime` boot + path_scan.

## Global Constraints

- **Provider id:** `dsh-native`. Command key: `dsh-jsonrpc-agent`. Also honor `DSH_RUNTIME_BIN` at probe/boot (SDK resolution order).
- **No path dep** on the local `dsh-rust-sdk` checkout. Pin only in `Cargo.toml`.
- **No version in `docs/`.**
- **Decode (locks § PD-3 + AR-7):** same contract as P1 — dsh `SdkProtocol` / `TransportClosed` / `JsonRpc` / `RequestTimeout` map to `decode_error` / `stream_closed` / `provider_error` / `timeout` per AR-7. Wrap `Session::run` in `tokio::time::timeout` (its receipt/idle waits are unbounded by design).
- **Capabilities (AR-6, documented narrower descriptor):** `text_prompt: true`, `session_restore: true`, `streaming: false`, `cancellation: false`, all other fields as `native_cli_limited()`. New dedicated const (e.g. `CapabilityDescriptor::native_cli_dsh_limited()`) with a doc comment citing AR-6 — never silently reuse or mutate `native_cli_limited()`. Emit exactly one `MessageDelta(final_response)` + one terminal event per execute. `cancel()` is an honest no-op that logs (no cancel RPC exists; do not kill the runtime to fake one).
- **No default npx.** No bundled runtime.
- **No `NATIVE_PREFERRED_FAMILIES` entry.**
- **No new Setup/Settings chrome.** Catalog listing is enough.
- **Reuse P1 patterns:** lazy session on first execute; probe via `which` + env; skip register when missing.
- **Toolchain:** same as P1.
- **Out of scope:** ACP dsh; plugin/cordis project bootstrap UI; raising capabilities; install wizard.
