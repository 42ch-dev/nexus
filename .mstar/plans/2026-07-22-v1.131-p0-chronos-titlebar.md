## Architecture lock (architect Seat 2)

- **Tauri:** keep native decorations; configure `titleBarStyle: "Overlay"`, `hiddenTitle: true`, and smoke-tuned `trafficLightPosition`. Do not use `decorations: false`, private macOS APIs, or JavaScript traffic-light controls.
- **Drag/safe area:** the web bar paints `#0D2B3E`; only empty background carries `data-tauri-drag-region`. Desktop reserves native traffic-light inset; logo, gear, title, theme, and health controls remain interactive.
- **Layout:** `RootLayout` is a viewport-height column (titlebar + `min-h-0` pane row). Presentational chrome lives under `layout/presentational/**` and is mirrored through Studio `@web-layout/*`; app behavior stays in wrappers.
- **Brand:** titlebar uses a transparent bright/white mark on ink. Remove the sidebar’s reserved logo row/sole logo-host behavior; do not place the square deep `primary` plate on the light sidebar.
- **Settings interface:** P0 mounts/stabilizes a thin typed controller around the existing single `SettingsModalHost` and wires the gear. P2 extends the same host with registry/routes/dirty guard; P0 must not create a second dialog or retain a full-page Settings link as primary behavior.
- **Failure policy:** native interaction smoke is a P0 acceptance gate. A titlebar residual/fallback is not an accepted substitute for `DF-V1131-CHRONOS-TITLEBAR`.
