## Product Framing

**User value:** A new author sees installed local agents as cards, picks one, and continues setup without guessing PATH or launch commands (local-first ACP client; no BYOK).

**Problem statement:** `R-V1100P0SMOKE-AGENT-SCAN` — agent step does not display locally available agent CLIs in a credible product surface.

**Target state:** Card-grid AgentPicker (status dots, outbound install/docs links), wired to scan + profile persistence; reusable beyond the wizard; empty/error/custom-launch acceptance-visible.

**Non-goals:** BYOK, in-app installers, Settings shell (**DF-70**), schema expansion, `@42ch/nexus-ui` AgentPicker promotion, treating human smoke as automated Done blocker.
