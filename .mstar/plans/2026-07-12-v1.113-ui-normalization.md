> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd`. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add missing DESIGN.md tokens (`sidebar-nav.disabled*`,
`listbox.maxHeight`, shared disabled opacity) and sweep **disabled-state**
inline `opacity-50` usages to shared tokens; close R-V1111P3QC1-S001.

states (not decorative opacity).

**blocked_by:** none — **independent of P0**; safe to run in parallel

### Task 1: DESIGN.md token additions

**Files:**
- Modify: `DESIGN.md` (repo root)
- Modify: `DESIGN.dark.md` (repo root; same token names; dark-appropriate values if needed)

**Interfaces:**
- Consumes: existing DESIGN.md token structure
- Produces: new token groups for disabled states + listbox

- [ ] **Step 1: Add `sidebar-nav` disabled token group**

  `sidebar-nav` is currently a flat object under `components`. Add disabled
  tokens as additional flat keys (additive, no restructuring):

  ```yaml
  # Added to existing components.sidebar-nav flat object:
  disabledOpacity: "0.5"
  disabledTextColor: "{colors.gray-700}"
  ```

  Follow the DESIGN.md token reference pattern (`{colors.gray-700}`), not
  CSS `var()` expressions.

- [ ] **Step 2: Add `listbox.maxHeight` token**

  New component group under `components`:

  ```yaml
  listbox:
    maxHeight: "320px"
  ```

- [ ] **Step 3: Add shared disabled opacity token**

  Place under `components.states` (which already holds `spinner`, `loading`,
  `empty`, `error`). Add a new `disabled` sub-object:

  ```yaml
  # Under components.states:
  disabled:
    opacity: "0.5"
  ```

  This follows the existing `states` pattern for cross-cutting state tokens.

- [ ] **Step 4: Mirror token names in DESIGN.dark.md**

  Same names; values may match light if opacity is theme-independent.

- [ ] **Step 5: Commit**
