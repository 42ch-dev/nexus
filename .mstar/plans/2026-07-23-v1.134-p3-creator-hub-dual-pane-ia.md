## Problem Statement

**User impact:** The Creator Hub is the product's primary creation surface, but it does not match the author's mental model:

| Today | Author expects |
|-------|----------------|
| Create via **dialogs/modals** | **Inline** create in the left workspace |
| Left = Create-only strip (V1.132) | Left = **usable 功能区** (tabs + create/select) |
| Selection → **full-page controller stub** | **Stable dual-pane** chrome; list stays |
| Entity kind not a linked dual-pane tab pair | **世界 / 作品** tabs on **both** panes, linked |
| Empty list unclear | Empty state: create from the left (i18n) |

This has been re-litigated across dogfoods; V1.134 locks the product correction.

## User value

Authors open 创作 and immediately work in a dual-pane workspace: create and switch entity kinds on the left, browse cards on the right, never lose the layout to a stub page or a modal wall. Empty workspaces teach the next action. Canvas deep-work stays on existing orthogonal routes.

## Goal

Replace the current Creator Hub model (left Sidebar Create-panel + right lists + controller stub + modal create) with a **dual-pane**:

- **Left = workspace 功能区** (inline create/select, **NO modal on hub**)
- **Right = card list** with empty state (zh-CN intent: "无内容，从左边创建"; en + zh-CN i18n catalogs)
- **World/Work (世界/作品) tabs on BOTH panes, linked** (one shared tab SSOT)
- **Dual-pane is stable chrome** — selection must not full-page-replace with today's controller stub

## Priority

**Must** (critical path of the iteration). **No Stretch.** Cut rather than add entity Chat, orch redesign, or canvas work.

## Architecture (product framing; architect locks contract)

`apps/web/src/pages/creator-hub-page.tsx` currently composes `CreatorEntityListsPanel` + Create-only left (V1.132 P3) + a controller stub when `selectedEntity` is set; create actions are dialogs. The redesign moves create to **inline** left-pane affordances, keeps the right pane as a card list with empty state, and introduces **shared World/Work tab state** linked across both panes (lineage: `useCreatorEntitySelection`).

**Canvas routes under `/works/:workId/*` and `/worlds/:worldId/*` stay orthogonal** — hub IA is hub-scoped.

**Evolves (does not reopen) shell parent IA:** footer / 工作区 parent / 创作|编排 mode switch stay. P3 changes **hub content** only — left becomes full workspace 功能区, not a left Menu dump of Worlds/Works (lists stay on the right).

Studio-first: dual-pane layout built/accepted in `apps/design-studio` (**author** eyeballs) before app wiring.

**Tech Stack:** React + Tailwind, DESIGN.md tokens, React Router, `@tanstack/react-query`, i18n (en + zh-CN).

**Execution:** mstar-sdd
