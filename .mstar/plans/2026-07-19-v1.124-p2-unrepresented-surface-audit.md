## Global Constraints

- **Studio import boundary** (`apps/design-studio/AGENTS.md`): same as P0; no `@xyflow/react`, no daemon, no contracts, no app providers.
- **V1.106 four-bucket classification (product-clear definitions):**

  | Bucket | Means (non-author reader) | When to use |
  |--------|---------------------------|-------------|
  | **`promoted primitive`** | Lives in `@42ch/nexus-ui`; pure presentational; reusable by Web + Studio (+ future consumers) | ≥2 consumers, stable props, RF/daemon/route-free. **Rare for canvas chrome this iteration** — P3 records; P2 does not force package moves. |
  | **`studio-local fixture`** | Studio shows it for visual review; code stays app-owned (often via `@web-*` extract) | Has visual surface worth reviewing; presentational layer extractable; not yet (or not ever) package-worthy. **Default for P2 fixtures.** |
  | **`web-only wrapper`** | Stays in `apps/web`; **no** Studio mirror required | RF layer *is* the UI, or daemon/route/product-state coupling with no clean presentational shell. Must still appear in the audit with rationale. |
  | **`future web product component`** | Not shipped / not ready; track for a later iteration | Genuinely new product UI. None expected in V1.124 audit scope. |

- **Studio-eligible gate (both must be true):** (a) visual surface worth reviewing (chrome, tokens, layout, state), AND (b) presentational layer can be extracted RF-free / daemon-free / contracts-free. If either fails → `web-only wrapper` with written rationale.
- **Locked product priority for fixtures this iteration** (do not reorder without compass edit):
  1. **Global Timeline overview** — V1.123 Timeline-first IA; cross-World entry chrome
  2. **Layer breadcrumb** — three-layer zoom affordance; authors see it constantly
  3. **Conflict-modal family** — shared destructive/resolve chrome across canvas surfaces
  4. **Alt-view toggles** — Outline / Strategy / WorldKB / Timeline alt-view chrome
  5. **Defer by default unless audit proves cheap:** `idea-input.tsx`, `canvas-nav-commands.tsx` (likely command/behavior-coupled)
- **P0 dependency:** Timeline node chrome is **out of P2** (owned by P0 via locked `@web-canvas/timeline-node-chrome`). Layer breadcrumb is independent (`@web-canvas/layer-breadcrumb`). Global Timeline needs **new** `@web-global-timeline/*` alias (see `surface-audit-checklist.md` §4.1 / §6).
- **Boundary SSOT:** `.mstar/iterations/v1.124/specs/surface-audit-checklist.md` — pre-classify + extract paths locked Phase 1; Execute deepens full file walk, does not reorder priority 1–4.
