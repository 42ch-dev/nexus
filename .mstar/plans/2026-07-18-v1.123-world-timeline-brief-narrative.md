# P1 — World Timeline Brief+Narrative Dual-Layer Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd` (recommended). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Extend V1.122's `TimelineCanvasAdapter` with a **Brief layer** (world-global era markers / world shape) alongside the existing Narrative layer (event timeline), add a Brief↔Narrative layer switcher, and make Brief the default World Timeline layer when Brief data exists.

> **Terminology note:** "Narrative" here refers to the Timeline layer (event-level), distinct from prose-craft narrative writing. "Moment" (referenced in downstream plans) is the Timeline layer (scene/beat-precise), distinct from Moment Context Assembly. See CONCEPTS.md § Narrative / § Moment.

**Architecture:** Frontend + backend additive extension. V1.122's `TimelineCanvasAdapter` (in `apps/web/src/components/canvas/timeline-canvas/`) gains Brief layer projection (data carrier per P0 architect lock — likely `block_type=era` KeyBlock entities or new Brief-on-World DTO); V1.122's existing event timeline becomes the Narrative layer; canvas header gains Brief↔Narrative layer switcher; default World Timeline layer is Brief (with Narrative fallback when Brief empty). Backend changes per architect lock (`GET /v1/daemon/worlds/{world_id}/timeline` promotion from `DF-V1122-DEEPER-WB` if Brief/Moment carrier requires it; or additive frontend-only if Brief rides V1.73 `kb.patch_entity`).

**Tech Stack:** TypeScript, React, `@xyflow/react` (React Flow), `@dagrejs/dagre`, `apps/web` (Vite SPA), `packages/nexus-ui`, vitest. Rust/daemon changes per architect lock.

### Adapter contract (architect LOCKED in `three-layer-architecture.md` §2 + §7 — extends V1.122 `TimelineCanvasAdapter`)

```ts
// apps/web/src/components/canvas/timeline-canvas/timeline-canvas-adapter.tsx (V1.123 P1 extension)

type TimelineLayer = 'brief' | 'narrative';

/**
 * Brief-era node data. `block_type=era` KeyBlock entity projected onto the
 * Brief when-axis. Era marker attributes read from `body.attributes`
 * (era_id / start_hint / end_hint / world_summary — freeform).
 */
interface TimelineEraNodeData extends WorldKbEntityProjection {
  [key: string]: unknown;
  layoutHint: 'brief';
  eraId?: string;        // body.attributes.era_id
  startHint?: string;    // body.attributes.start_hint
  endHint?: string;      // body.attributes.end_hint
  worldSummary?: string; // body.attributes.world_summary
}

interface TimelineLayerAdapter extends TimelineCanvasAdapter {
  surfaceKind: 'timeline';
  /** Default layer on World Timeline entry (architect LOCKED). */
  defaultLayer: 'brief';   // with fallback to 'narrative' when Brief empty
  /** Project the graph for a specific layer. */
  projectGraphForLayer(graph: TimelineGraph, layer: TimelineLayer): {
    nodes: Node<TimelineNodeData | TimelineEraNodeData>[];
    edges: Edge<TimelineEdgeData>[];
  };
  /** Inherited from V1.122 — MUST delegate to active layer. */
  projectGraph(graph: TimelineGraph): { nodes; edges };
  // ... rest per V1.122 §3.1
}
```

The V1.122 `projectTimelineGraph` partition (`timeline-canvas-adapter.tsx:300-373`) extends additively: dated/undated events + context clusters (V1.122 preserved) + a new partition for `block_type === 'era'` entities → `TimelineEraNode` on the Brief when-axis. V1.122 Narrative regression tests stay green because the existing partition logic is unchanged for `block_type === 'event'`.
