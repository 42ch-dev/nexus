## Prepare Package (Product)

### Specify

- **Problem:** token-correct but tactile-poor components; `dialog.tsx` hardcodes `bg-black/40` despite `scrim`; `states.tsx` raw color-mix; badges raw color-mix; no states matrix in studio.
- **Scope:** nexus-ui promoted set (Button/Badge/Card/Input/Label/Textarea/Select/Toast) + keep-web (Dialog/Sheet/Tabs/Table/States) + badge family (status-badge, task-kind-badge, maturation-indicators) + studio components gallery.
- **Non-goals:** package promotion; new components; prop renames/removals; app-surface adoption beyond gallery fixtures (P2/P3); i18n/copy rewrites; wire/desktop-native changes.
- **Draft DoD:** AC-P1-1…7.

### Clarify (locked — PM, autonomous)

- **Elevation recipes:** interactive cards rest `elevation-1` → hover `elevation-2` + `translateY(-1px)` (160ms ease-standard); popovers `elevation-3`; dialogs/sheets `elevation-4`; reduced-motion safe.
- **Scrim convergence:** Dialog/Sheet overlays → `bg-scrim`; remove `bg-black/40`. Command palette scrim converges in P2 (same token).
- **Focus ring:** two-layer contract kept; inner ring re-verified against ink `background-100` dark; AA ≥ 3:1 evidence.
- **Content voice opt-in:** `Card.Title` gets an **additive** documented opt-in per the contract authored in P0 spec T8 — a new optional `voice?: 'interface' | 'content'` prop on `CardTitle` (`packages/nexus-ui/src/components/card.tsx`), default `'interface'` preserving the current `text-heading-16 font-heading` sans exactly; `voice="content"` swaps to `font-display text-display-20 tracking-tight`. Existing call sites compile and render identically (no breaking change; no CVA variant on `Card` root). Greppable (`voice="content"`). No serif in Button/Badge/Input/Table/Tabs.
- **Badge family:** raw color-mix → P0 tint tokens; soft/solid tones unchanged semantically.

### Plan (technical)

- **T1 — nexus-ui elevation/motion pass:** Button (hover/pressed), Card (elevation recipe + `CardTitle voice` opt-in per P0 spec T8 — additive prop, default preserves current sans), Badge/Input/Select/Textarea/Toast token alignment; CVA extension only.
- **T2 — keep-web pass:** Dialog/Sheet scrim + elevation, Tabs/Table hover recipes, States tokenized error surface + serif empty-state headline; sweep arbitrary values.
- **T3 — Badge family + hardcoded sweep:** status-badge / task-kind-badge / maturation-indicators → tokens; grep-clean ui layer; exceptions documented.
- **T4 — Studio states matrix:** variants × states (default/hover/focus/disabled/loading) × light/dark for the full component set; builds + tests green.
