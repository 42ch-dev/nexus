**Goal (product outcome):** A contributor opens Design Studio → Tokens page, toggles light/dark, and can **find and inspect every** canvas Timeline / Layer / Soul-viz-timeline token that already exists in `tooling/design-tokens/src/tokens.css` — labeled swatches, both theme values. After P1, "token in CSS but invisible in Studio" is no longer true for the V1.122/V1.123 Timeline stack, and a written recurrence gate stops the same debt from accumulating again.

**Architecture:** Pure-CSS-variable gallery update. **IA locked** in `tokens-gallery-audit.md` §4 — four groups (Canvas — Timeline accent spine / Layer accents / Outline Timeline pins / Soul Viz — Timeline axes) covering nine tokens. Extend `CANVAS_TOKEN_GROUPS` (same entry shape as existing spines). No new components; no daemon; no App changes; no invented tokens (NG-9). Token SSOT stays in `tokens.css`; the gallery is a read-only projection.

**Tech Stack:** React 18, Tailwind 3, `@nexus/design-tokens`, lucide-react.

**Execution:** mstar-sdd (multi-task plan)

## Global Constraints

- **Token SSOT**: `tooling/design-tokens/src/tokens.css` is generated/derived from root `DESIGN.md` + `DESIGN.dark.md`. The gallery **never** invents values. If a token is in the gallery but not in CSS (or vice versa) → that is a defect to fix in this plan.
- **Light + dark dual values** must both render in the gallery (the existing pattern: CSS variable in `light` block + override in `.dark` block; gallery shows both via the theme toggle).
- **No new tokens in this plan**: P1 surfaces tokens that already exist in `tokens.css`; it does not add new tokens. If a token is missing on both sides, that goes to a follow-up residual / roadmap — not silent gallery invention (compass NG-9).
- **Studio Tests**: `pnpm --filter design-studio test` must remain green. Existing tokens-page smoke tests must still pass.
- **i18n**: Studio Tokens page is developer-facing — no `t()` calls; existing English labels. Labels use token names / short product group names (Canvas — Timeline, Canvas — Layer accents, Soul Viz — Timeline axes) — not marketing copy.
- **AGENTS.md UI Component Policy § "Tokens need a gallery"**: this plan operationalizes that rule for the V1.122/V1.123 backlog **and** hardens it against recurrence (Task 3).
