## Global Constraints

- **IDs frozen:** `claude-native`, `codex-native`. Discovery keys stay `claude` / `codex`.
- **Facade frozen:** `ProviderAdapter` method set; execute still Prompt-only; stream still exactly one terminal `OpFinished`|`OpFailed`.
- **Deps:** only `claude-codes` and `codex-codes`, each `{ default-features = false, features = ["async-client"] }` (drops `sync-client`; claude's `auth` feature is not in default and stays off — AR-3). Pin in workspace `Cargo.toml` `[workspace.dependencies]`; never write the version in `docs/`.
- **Decode (locks § PD-3 + AR-7):** skip+debug for unknown **nested** variant / unknown codex method; one `OpFailed` for unknown claude **top-level** type, typed-decode failure, or stream abort (AR-1 correction). Fixed terminal tokens `decode_error` / `stream_closed` / `provider_error` / `timeout` / `io_error` and verbatim `error_message` per AR-7. CLI skew = warn only.
- **Capabilities:** keep `native_cli_limited()` as-is — do not raise false fields; do not silently drop `streaming` / `cancellation` / `session_restore`. If crate resume cannot honor `session_restore`, STOP and document a narrower descriptor (architect), do not quietly change the claim.
- **No dual stack:** after T2/T3, delete self-written parsers. No leftover `--print` / `exec --json` fallback.
- **Codex sandbox (AR-4):** every `turn/start` carries `approval_policy: AskForApproval::Never` + `sandbox_policy: SandboxPolicy::ReadOnly { network_access: None }` (headless parity with today's `-s read-only`, never more writable). Any approval server-request is auto-answered from existing native permission classification: `Allow` → accept, `Deny`/`Ask` → deny. No author prompt.
- **Tests:** delete `echo --print` and fake-script JSONL tests that pretend to be the vendor protocol. Mapper tests use crate `test_cases` / fixtures. Live CLI tests optional / feature-gated.
- **Toolchain:** `SQLX_OFFLINE=true`; `cargo +nightly-2026-06-26 fmt --all`; clippy `--all-targets -- -D warnings`. `CARGO_TARGET_DIR` if set in env.
- **Out of scope:** ACP; dsh; capability descriptor raises *or silent drops*; crate forks; docs version pins; approval UI; new Setup/Settings chrome.
