**Goal (user value):** Wherever transport fails (resume gate, desktop launch gate, Connection settings, mutation toasts), the author sees the **same** kind-matched language and recovery CTAs as the create dialog — one mental model, no leftover generic blob — via a shared presentational block (Studio-first → `@42ch/nexus-ui`).

**Architecture:** Studio-first `<TransportErrorBlock>` primitive → `@42ch/nexus-ui` → thin re-export wrapper consumed by `FingerprintGate`, `DaemonLaunchGate`, `settings-connection-section`, and `useErrorToast`. One copy source for transport-failure headlines, bodies, and CTAs.

**Tech Stack:** React 18 + TypeScript + Tailwind + Vitest + i18next.

**Execution:** mstar-sdd (multi-task)

5. **Task order:** T1 (Studio) → T2 (promotion) → T3 (FingerprintGate) → T4 (DaemonLaunchGate) → T5 (toasts) → T6 (settings + regression). Serial; each depends on T2 (promoted primitive available) or can be reordered — but Studio + promotion MUST complete before app wiring claims done.

## Global Constraints

- Studio-first (root `AGENTS.md` UI Component Policy): the primitive lands in `apps/design-studio` first; promotion to `@42ch/nexus-ui` requires a plan/spec promotion-list entry per `packages/nexus-ui/AGENTS.md`.
- The primitive is **presentational only** — no daemon calls, no routing, no product state. Caller composes surrounding behavior.
- i18n: caller-owned copy flows in via `t()` strings passed to the primitive; the primitive does **not** import `react-i18next` (keep the package pure).
- TypeScript strict; no `any` for `TransportErrorKind`.
- WCAG 2.1 AA floor (apps/web AGENTS): keyboard path, focus-visible ring, contrast in both themes, reduced-motion.
- Voice & Content: Title Case headlines, sentence case bodies, verb-only CTAs.
