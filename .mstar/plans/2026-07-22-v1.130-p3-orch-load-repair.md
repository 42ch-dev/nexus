## Architecture lock

- **Dependency:** implementation starts after P1 shell boundaries are merged, preserving Wave 3 P2 ∥ P3a. Read-only RCA evidence may be gathered earlier but does not relax the dispatch gate.
- **Healthy contract:** (1) `GET /v1/daemon/runtime/health` succeeds, (2) protected request is not rejected by auth, and (3) the endpoint-required engine/registry exists. The target endpoint response, not a new aggregate health endpoint, is authoritative for step 3.
- **Classification:** canonical `503 service_unavailable` caused by absent engine/registry renders `UnavailableState`/honest empty. Network/TLS/timeout is transport failure; 401/403 is auth failure; 404 is missing resource; malformed/other 5xx is load failure. Do not classify every 503 or message substring as “engine down” when a stable canonical code is available.
- **Ownership:** pages/query hooks own presentation and retry; `BrowserClient` owns canonical error parsing; daemon handlers own status/envelope; `WorkspaceState` owns engine/registry availability. No UI engine-autostart and no client-side fake data.
- **RCA matrix:** record request path, fixture/runtime preconditions, actual status/body, expected status/body, and root owner for Strategy list+detail, Sessions list, Modules list+detail. Fix the narrowest shared boundary where failures converge.
- **Wire:** current generated DTOs and endpoint shapes are expected to suffice. If RCA proves a response shape is missing or wrong, amend this plan and `wire_contracts_changed` before schema/codegen work.
