The residual descriptions in `status.json` reflect the pre-fix state and were not updated post-merge.

**Current `main` state** (verified at `bba96c61`):
- **T1/T2 (SAN-vs-bind-host):** `cert_covers_bind_host` at `tls/mod.rs:228` validates the persisted cert's SAN against the current `bind_host` (loopback, `0.0.0.0`, `::`, hostname, and IPv4/IPv6 cases). `try_load_existing` at line 89 calls it; on mismatch returns `None` → falls through to `generate_and_persist` at line 56. `build_subject_alt_names` at line 191 implements loopback always + bind host + wildcard skip. **Code is done.**
- **T3 (graceful-shutdown):** `boot.rs:864` already uses `handle.graceful_shutdown(Some(shutdown_grace))` where `shutdown_grace` is `Duration::from_millis(config.shutdown_grace_ms)` (line 842), matching the plain-HTTP path. **Code is done.**
- **Existing tests** (`tls/mod.rs` lines 323–487) cover: SAN match reuse (line 331), SAN mismatch regeneration (line 353), IPv4 SAN (line 384), hostname SAN (line 394), wildcard skip (line 401), corrupt file regeneration (line 426), permissions (line 448), fingerprint format (line 417).

**This plan therefore verifies the existing implementation and closes the remaining test gaps** rather than building from scratch.
