# P1 — Strategy Spatial Edge Rewiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `mstar-sdd`. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add spatial `onConnect` edge creation/rewiring to the Strategy canvas so authors can draw and reconnect transitions directly on the graph, reaching the same spatial-editing parity that Outline (V1.108 C1) and World KB (V1.73/V1.74) already enjoy.

**Architecture:** Strategy canvas nodes gain React Flow `<Handle>` connection points. `onConnect` creates a draft edge that opens the edge inspector (condition/label fields) before committing via `strategy.patch_transition`. **Architect lock (§5.2 Q3):** the shipped DTO is **rewire-only** — `patch_transition_inner` returns `strategy_transition_missing` (no `next` field) or `strategy_transition_not_found` (no matching `old_target`) when the author draws a brand-new transition. P1 adds an **additive `op: "create" | "update"` field** to `StrategyPatchTransitionRequest` (default `"update"`, backward-compatible) so spatial create works; reconnect reuses the existing rewire path (single payload, §5.2 Q4). A keyboard path (choose source → target → edge kind) satisfies §4.4 pointer-alternative accessibility.

**Tech Stack:** `@xyflow/react`, TypeScript, `@42ch/nexus-contracts`, Tailwind + DESIGN.md tokens, Vitest + RTL.

**Execution:** mstar-sdd

**Primary spec:** `.mstar/iterations/v1.109/specs/strategy-edge-rewiring.md` (§5.1 product-complete — FB-SE-000..004 expanded)

## Architectural context

**Current state:**
- `strategy-canvas.tsx` renders Strategy graph read-only with live overlay
- `use-strategy-canvas.ts` hook manages graph state
- `strategy-patch-transition-request.schema.json` exists (V1.71) — supports `source_state_id`, `old_target`, `new_target`, `condition`, `transition_kind`. **Rewire-only** (§5.2 Q3 evidence).
- Edge inspector (`strategy-canvas/inspectors/edge-inspector.tsx`) exists for editing existing edges
- No `onConnect` handler — edges cannot be created spatially

**Target state:**
- Strategy nodes render `<Handle type="source" />` + `<Handle type="target" />`
- `onConnect` creates a draft edge → opens edge inspector with condition/label fields
- Commit sends `strategy.patch_transition` with `op: "create"` for new edges; 409 conflict → conflict modal
- Edge reconnection: drag from existing edge end to new target → `op: "update"` (default) single reconnect payload (§5.2 Q4 — no delete+create)
- Keyboard path: dialog "choose source → choose target → choose edge kind"
- **Wire change:** `StrategyPatchTransitionRequest` gains optional `op: "create" | "update"` (default `"update"`); `old_target` becomes optional when `op: "create"`; daemon handler gains create branch (set `next` when absent, or append rule when `next` is a map); schema + codegen + daemon updated in one commit
