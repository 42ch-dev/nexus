## Context

`apps/desktop/src-tauri/icons/` ships **placeholder icons**: the directory README states they are *"a placeholder generated from a solid-color source … Replace the source artwork before the first public release."* The macOS dock icon, Windows taskbar/installer, and bundle metadata all currently show placeholder artwork. V1.83 established the Nexus logo family (`packages/nexus-ui/assets/logos/` — PNG sources under Git LFS + canonical SVG variants) and the brand palette (deep blue `#1E3A5F`, cyan `#25D1E0`, white). The `@tauri-apps/cli` (already a devDep) provides `tauri icon <source-1024.png>` to regenerate every required OS icon format from one 1024×1024 source. This plan composes a proper branded app-icon source, regenerates all icon formats, and updates docs/refs.

## Specify

- **Problem**: The desktop app icon is a placeholder; the product is not recognizably Nexus at the OS level (dock, taskbar, installer).
- **User value**: The app icon (dock, taskbar, installer) becomes recognizably Nexus — the first OS-level brand surface a user sees when launching or installing the app; completes the V1.83→V1.84→V1.85 brand arc at the OS level.
- **Scope**:
  - Compose a 1024×1024 Nexus app-icon source: the logo mark on the branded background (deep blue, with the cyan/white N), with OS-icon-appropriate padding. Deterministic vector composition from the V1.83 logo SVG family (faithful, not generative re-imagining). Commit the SVG source (normal git) and rasterized 1024×1024 PNG (Git LFS, per V1.83 binary policy) under `apps/desktop/src-tauri/icons/source/`.
  - Run `pnpm --filter desktop exec tauri icon src-tauri/icons/source/source-1024.png` from `apps/desktop` cwd to regenerate all icon formats, overwriting the existing placeholder icon files in-place. The existing root-level `icons/source-1024.png` placeholder source is superseded by the new branded source under `icons/source/`.
  - Update `apps/desktop/src-tauri/icons/README.md`: drop "placeholder" wording; document the source + regeneration command.
  - Add `apps/desktop/src-tauri/icons/source/*.png` to `.gitattributes` LFS tracking.
  - Verify `tauri.conf.json` `bundle.icon` refs (`32x32.png`, `128x128.png`, `128x128@2x.png`) resolve to branded PNGs.
- **Non-goals**:
  - Re-imagining the logo concept (faithful composition only).
  - New CI legs for non-macOS builds (icon formats generated for completeness; no new matrix).
  - Editing `apps/web/**`, `.github/workflows/**`, `packages/nexus-ui/package.json` exports, root `DESIGN.md` brand values.
  - Mobile packaging.
- **DoD (draft)**: branded 1024×1024 app-icon source committed; aesthetic sign-off gate executed (presentation or explicit deferral recorded); `tauri icon` regenerated all icon formats; README updated (no "placeholder"); bundle refs resolve; local desktop-bundle build succeeds; the dock icon is recognizably Nexus.

## Clarify

- **Where does the source live?** Commit the SVG source + rasterized 1024×1024 PNG under `apps/desktop/src-tauri/icons/source/` (or alongside the logo family in `packages/nexus-ui/assets/app-icon/`). PM picks; keep it discoverable + LFS-scoped. **Decision:** `apps/desktop/src-tauri/icons/source/` (the icon is a desktop asset, not a cross-app brand export; avoids widening `@42ch/nexus-ui` exports).
- **Aesthetic sign-off?** Present the composed app-icon source (or a downsized render) for user aesthetic sign-off **before** the full `tauri icon` regeneration, since the dock icon is high-visibility. If the user defers, proceed with best-judgment composition and record the deferral note.
- **macOS squircle?** Tauri applies the platform masks from the full-square source; compose with ~10% padding so the mark isn't cropped. Verify with a dock preview render.
- **LFS scope?** Add `apps/desktop/src-tauri/icons/source/*.png filter=lfs diff=lfs merge=lfs -text` to `.gitattributes`, consistent with V1.83 policy (binary source PNGs → LFS; regenerated small-format PNGs → normal git). The `.gitattributes` file is P0-owned in this iteration (P1 does not touch it).
- No open high-impact ambiguity.

## Plan

1. **Compose the app-icon source.** Author a 1024×1024 SVG with the brand deep-blue background (`#1E3A5F`) filling the canvas and the Nexus N mark (from `logo-primary.svg` / `logo-white.svg`) centered with ~10% padding in cyan/white. Rasterize to `source-1024.png` (1024×1024 RGBA). Place both files under `apps/desktop/src-tauri/icons/source/` (SVG normal git; PNG Git LFS). The existing root-level `icons/source-1024.png` is the placeholder source and is superseded. The composition stays deterministic and faithful to V1.83.
2. **Run the sign-off gate.** Present a downsized render (e.g. 256×256 + a mock dock tile) to the user; regenerate on approval, or proceed on best judgment if the user explicitly defers.
3. **Regenerate icon formats.** From `apps/desktop` cwd, run `pnpm --filter desktop exec tauri icon src-tauri/icons/source/source-1024.png`. `tauri icon` emits all OS icon formats into `src-tauri/icons/` (relative to `apps/desktop`), overwriting the existing placeholder files in-place. (`--filter desktop` sets cwd to `apps/desktop`; the path is relative to that directory.)
4. **Update docs and LFS tracking.** Rewrite `icons/README.md` (source provenance + regeneration command; drop "placeholder") and add `apps/desktop/src-tauri/icons/source/*.png filter=lfs diff=lfs merge=lfs -text` to `.gitattributes` (consistent with V1.83 policy: binary source PNGs under LFS; regenerated small-format PNGs stay normal git).
5. **Verify.** Confirm `tauri.conf.json` `bundle.icon` refs resolve; run `pnpm -w run sidecar` and then `cargo build` from `apps/desktop/src-tauri/` (or use the CI desktop-build leg); capture evidence that the dock icon is visually Nexus for QA.
6. **Rollback.** Asset + config only; revert the plan branch if a regression appears.
