## Product Framing

**User value:** ACP Agent is the hard dependency for creative work — select it first. Workspace stays choosable but defaulted (`~/Documents/nexus/default`) to reduce friction. Daemon readiness is **not** a wizard step (owned by P0 gate).

**Author journey (after P0 Ready):** `/setup` opens on Agent → Continue → Workspace (default shown, Browse optional, bootstrap on Continue) → Done → `/works`.

**Iteration gate:** Must after P0; before P2 chrome polish (P2 restyles the same three steps).

**Non-goals:** Portrait geometry / top Steps chrome (P2); Tauri agent scan; Settings IA redesign; multi-workspace; auto-wiping data on Re-run Setup.

1. Wizard step indicator / machine lists **only** Agent, Workspace, Done (no Welcome, no Daemon).
2. Step 1 Agent: scan + AgentPicker + custom command escape hatch; Continue requires selection or custom command; scan runs only after P0 Ready.
3. Step 2 Workspace: shows default `~/Documents/nexus/default`; Browse works on desktop; Continue runs `ensureSetupBootstrap` then advances.
4. Step 3 Done: `setAgentProfile` + `markCompleted` → `/works`.
5. Welcome and Daemon wizard steps are gone from UI (components deleted or demoted to non-step helpers).
6. Settings Re-run Setup (V1.103 R1): confirm → marker clear → fullscreen gate (P0) → `/setup` on Agent step; workspace path and agent profile preserved.
7. Prefer no schemas change.
