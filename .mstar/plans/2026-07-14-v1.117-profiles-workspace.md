## Problem Statement

Authors expect a Profile identity and a workspace that belongs to that Profile.
Today Setup creates a bare creator id, Settings says "Workspace", and
`workspace_path` is global.

## Scope

### In scope

- Default Profile guarantee + Setup Profile name field
- Settings Workspace → Profiles (i18n + section)
- Per-Profile workspace path storage + switch Profile activates path
- Profiles settings: edit name + workspace path

### Not in scope

- Extra Profile fields; cloud sync
