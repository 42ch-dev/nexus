# P1 — Thin Settings Host (DF-70 Slice A)

**Goal:** Ship a thin Settings host that mounts the existing app-shared `AgentPicker` so authors can change local agents after first-run.

**Architecture:** Control Room **Settings** footer-utility nav → **`/settings`** under `SetupGate`→`RootLayout` → `settings-page.tsx` mounts `apps/web/src/components/setup/agent-picker.tsx` → persist via **`DesktopCapabilities.setAgentProfile`** (setup `finish()` parity). Studio-first for Settings chrome. Do **not** promote AgentPicker to `@42ch/nexus-ui`.

**Tech Stack:** React Router, `apps/web` layout/shell, AgentPicker, Design Studio fixtures, Vitest.

**Execution:** mstar-sdd

**Tier:** **Must (P1)**

## Product Framing

**User value:** Change the default local ACP agent without re-running the full setup wizard.

**Author-facing outcome:** From Control Room, open Settings → see AgentPicker → select installed agent or custom launch → profile persists across reload.

**Non-goals:** Full multi-section Settings IA (≥2 product sections); nested Settings taxonomy; BYOK; in-app installers; AgentPicker package promotion; Iconify; schemas; Stretch P2 chrome as Must blockers for this plan.

## Acceptance Criteria (Must — this plan)

1. **Nav:** Control Room shows **Settings** in sidebar footer utility (above profiles) and mobile nav — not a second nav system; not inside Creator/Orchestrator tab groups.
2. **Route:** Activating the entry opens **`/settings`** (single host page; no multi-section Settings sidebar IA).
3. **Content:** That page’s primary product content is `AgentPicker` from `apps/web/src/components/setup/agent-picker.tsx`. Settings is a **host**, not a wizard re-run (no forced multi-step setup flow).
4. **Persistence:** Selecting an installed agent or custom launch calls **`desktop.setAgentProfile(name, launchCommand?)`**; Vitest covers route render + picker mount; reload survival on desktop is confirmed by the **separate human smoke gate** when scheduled.
5. **Studio-first:** Settings chrome / Agent page fixtures pass visual acceptance before App wiring.
6. **Wire / Non-Goals:** Prefer `wire_contracts_changed: false`; no BYOK; no AgentPicker → `@42ch/nexus-ui`; no full Settings IA.
