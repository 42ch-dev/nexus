## Prepare Package (Product)

### Specify

- **Problem statement:** Workspace Continue fails on dogfood (F7); Reset appears for all errors; inline feedback missing or toast-only. Failure mode A (empty profile name disables Continue) is addressed in P1 but documented here for repro completeness.
- **User value:** First-run completes on happy path; recoverable errors are retryable without destructive Reset.
- **Scope:** Bootstrap / `updateCreator` failure paths; inline alert region; Reset gated to migration/DB-class only. Primary spec AC-P0-*.
- **Non-goals:** AgentPicker (P2); profile/path polish (P1) except happy-path verification with name `default`.
- **Target state:** IC-1, IC-2; inline alert is primary signal (AC-P0-4).
- **Draft DoD:** All AC-P0-* pass on desktop; tests cover classifier matrix (happy, soft bootstrap, soft display name, migration).

### Clarify

- **Decisions (locked):**
  - Happy path must not show Reset.
  - Inline `role="alert"` above CTA row whenever Continue fails; toast is secondary.
  - Reset **only** for migration/DB-class failures (message contains `migration`, daemon migration stderr, or explicit desktop classifier).
  - Display-name persist failure: soft — inline error, **no Reset**, **no advance**; bootstrap already succeeded.
  - Workspace path persist failure: soft — inline error, no Reset, no advance.
  - Continue stays enabled after soft failure for one-tap retry (AC-P0-5).
- **Copy (writing §5.3):**
  - Inline alert: body = daemon message or `error.*` fallback; helper = `continueError.helper.soft` vs `continueError.helper.migrationDb` by class.
  - Reset CTA: `action.resetLocalDatabase` (short **Reset** only).
  - Toast secondary only; deprecate conflated `toast.workspaceBootstrapFailedDescription` for inline-primary UX.
- **Open questions (architect §5.2):**
  - ~~Exact IPC error-code mapping for migration-class vs generic bootstrap.~~ **Resolved** — web classifier (AD-P0); optional Rust code only if T1 repro ambiguous.
  - ~~Whether Tauri should expose structured `{ code, message }` vs string matching only.~~ **Resolved** — string + existing structured codes sufficient; no new bootstrap enum in default path.
  - Root-cause repro on dogfood machine (Task T1 evidence).

### Plan

- **Option A — Web classifier only:** Pure TS `classifySetupContinueError(phase, err)` drives Reset + inline copy. **Trade-off:** bootstrap plain-string errors rely on substring rules.
- **Option B — New Rust `BootstrapError` enum on every failure path:** **Trade-off:** desktop-crate churn for V1.119 polish slice; deferred unless T1 requires.
- **Selected Approach:** Option A — matches `wire_contracts_changed: false`; reuse HTTP `error.code` + optional existing Tauri codes.
- **Long-term Target State:** Setup Continue failures are phase-aware, inline-first, Reset only for migration/DB recovery.
- **Durable Slice for This Batch:** Classifier module + inline alert region + derived `showReset` + workspace-path inline promotion + classifier tests.
- **Roadmap if Split:** N/A — single P0 plan.
