## Problem Statement

**User impact (author, emphatic):** Create belongs in the **original left menu / sidebar functional area** — the tall zone above 创作|编排 and 工作区 in the **shell sidebar**, not inside the main content pane. V1.134 P3 put create in **Content’s left column** (`CreatorHubDualPane`) and **hid** the sidebar create panel on hub routes via `isCreatorHubSurface`. Author screenshot shows a nearly empty white sidebar while create form sits in the main content pane. **That is the opposite of the ask.**

### Anti-misread (read before implementing)

| Misread | Correct interpretation |
|---------|------------------------|
| “功能区 = content dual-pane left” | **Wrong** — 功能区 = shell **sidebar menu slot** (`Sidebar` / `panelContent`) |
| “Empty state 从左边创建 means content-left” | **Wrong** — copy must match **sidebar** `panelContent` create after fix |
| “Keep dual-pane, move labels only” | **Wrong** — remove content-left create column entirely |
| “V1.134 P3 AC-12 is still valid” | **Wrong for author** — superseded by V1.135; `R-V1134P3-001` |

| Today (wrong) | Author expects |
|---------------|----------------|
| `isCreatorHubSurface` → `panelContent` undefined (empty sidebar) | Sidebar **always** shows create on 创作 hub |
| `CreatorHubDualPane` left column = create form | Content = World/Work tabs + card list / empty only |
| Empty state “从左边创建” points at content-left | Empty state points at **sidebar** create |

**Code anchors:** `sidebar.tsx` L88–90, L134–135; `creator-hub-page.tsx` mounts dual-pane.

## User value

Authors open 创作 and use the **left shell** to create worlds/works; the main pane is for browsing entities. No wasted empty sidebar.

## Goal

1. **Restore** `CreatorCreatePanel` as `ShellSidebarChrome` `panelContent` on `/works` and `/worlds` (remove hub hide guard).
2. **Remove** content dual-pane left-create; hub content becomes **single browsing surface** (tabs + cards / empty).
3. Update empty-state copy and Studio fixtures so “左边” = sidebar, not content-left.
4. **Rewrite** `workspace-parent-shell-ia` knowledge so V1.134 “hub create in content” is marked incorrect for author intent (Task 4).

## Priority

**Must.** No Stretch. **Cut** content dual-pane left-create — do not keep “for compatibility.”
