## 1. Problem Statement

Brand and design-system changes have a high visual blast radius even when behavior is unchanged. V1.83 needs closeout that verifies package shape, asset handling, token consistency, Web application, and documentation before the integration branch is ready for PR.

Closeout must judge the product slice the user asked for: authors should see a more coherent Nexus workspace through the shell and base primitives, while unchanged workflows remain stable. It should not expand the acceptance bar into a full visual redesign.

## 2. Scope

- Consolidate QC tri-review findings from the integrated `iteration/v1.83` HEAD and assign targeted fixes.
- Dispatch QA for light/dark visual checks and focused workflow regression.
- Verify Git LFS tracking for PNG source/provenance assets and regular-git SVG text assets.
- Verify package export boundaries: `@42ch/nexus-ui` exposes assets/tokens/theme only, no React component library or Web app internals.
- Verify root DESIGN SSOT and Web DESIGN mapping relationship: root token values remain canonical; Web files map or alias without becoming a second brand source.
- Verify package and Web checks, including package resolution from `apps/web`.
- Confirm product acceptance against the iteration boundary: visible brand value in shell/base primitives, no private platform implementation, and no full-page redesign creep.
- Update `.mstar/status.json`, compass plan states, iteration index, and residuals using structured fields for state and residual lifecycle.
- Run iteration-close compound after all plans are `Done`.

## 7. Risks

- Visual QA may require manual browser review if automated tests cannot capture contrast or logo placement.
- Residual handling must not be narrative-only; accepted leftovers require root `residual_findings` rows.
- Closeout can miss architecture drift if it checks only screenshots; QC/QA must also inspect package exports, import paths, and DESIGN mapping text.
- P0/P1/P2 may finish on separate topic branches; closeout review must use integrated `iteration/v1.83` HEAD so token/package/Web interactions are tested together.
