# P2 — Form Field Component Promotion

**Goal:** Promote `Input`, `Label`, and `Textarea` into `@42ch/nexus-ui` under a locked form-field accessibility and composition contract.

**Architecture:** `@42ch/nexus-ui` owns pure presentational controls. Apps compose labels, helper/error copy, validation behavior, submit handling, daemon state, and routing. Design Studio demonstrates the composition pattern without becoming an app shell.

**Tech Stack:** React 18, TypeScript, `@42ch/nexus-ui`, `apps/web`, `apps/design-studio`, Vitest, Tailwind token classes.

**Execution:** mstar-sdd

## Product Framing

**User value:** Contributors should be able to reuse the same accessible form primitives across Design Studio and Web without copying class strings or inventing field semantics per screen.

**Problem statement:** V1.99 deferred Input/Label/Textarea because promotion without helper/error/required semantics would only move code, not mature the component system.

**Target state:** The field primitives are shared, tested, and consumed through approved imports; field composition semantics are documented and demonstrated in Design Studio before the slice is treated as complete.

**Deferral closure:** This plan must visibly resolve the V1.99 reason for deferral: form-field semantics and app/package ownership. A lift-and-shift of existing app-local files is not sufficient.

**Non-goals:** No `Select` promotion, no package-level form framework, no broad rewrite of every Web form, no validation library adoption, and no schema changes.

## Global Constraints

- Iteration primary spec: `.mstar/iterations/v1.100/specs/form-field-contract.md`.
- Blocked by the P1 guardrail contract for promoted wrappers.
- Promote only `Input`, `Label`, and `Textarea`.
- Package code must not import app code, daemon clients, routing, layouts, or Tauri helpers.
- Package APIs must not own validation messages, submit behavior, daemon data, routing, or product copy.
- Web keeps compatibility through P1-approved thin wrappers; Design Studio imports promoted controls directly from `@42ch/nexus-ui`.
- The package must not export a stateful `FormField` wrapper in V1.100.
- `wire_contracts_changed: false`.
