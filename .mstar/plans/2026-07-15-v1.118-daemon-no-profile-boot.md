### Specify

- **Problem:** Daemon requires `active_creator_id` to open `state.db`; empty home → fatal boot (worse after V1.105 always-auto-start).
- **User value:** Local-first install works: daemon runs first, Profile later.
- **Scope:** System dir init, lazy DB open, health + creators without Profile, gated business APIs. See `primary_spec` AC-P0-*.
- **Non-goals:** Silent Default Profile auto-create; platform auth; medium residuals; mandatory wire changes.
- **Target state:** IC-1–IC-4 in delivery compass.
- **Roadmap if split:** N/A — single P0 plan.
- **Draft DoD:** All AC-P0-* pass; desktop clean-home E2E; opportunistic V1.117 residuals on touched files.
