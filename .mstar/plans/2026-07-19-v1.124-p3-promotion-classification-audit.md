## Global Constraints

- **V1.106 classification scheme** (canonical, four buckets — same as P2):
  - `promoted primitive` — pure presentational, reusable across `apps/web` + Studio + future external consumers; lives in `@42ch/nexus-ui`.
  - `studio-local fixture` — Studio-useful visual but App-specific; Studio fixture only, no package promotion.
  - `web-only wrapper` — App-coupled (RF / daemon / contracts / product state); stays in `apps/web` with no Studio mirror.
  - `future web product component` — genuinely new product UI not yet shipped; track for future iteration.
- **Product promotion criteria (all must be true for `promoted primitive`):**
  1. **Reuse:** ≥2 real or near-term consumers (e.g. Web + Studio, or two App surfaces) — not "might be nice in a package."
  2. **Purity:** renders without daemon, routing, RF node types, contracts, app providers, localStorage, Tauri.
  3. **Contract:** props are presentational and stable enough to document in `packages/nexus-ui/AGENTS.md`.
  4. **Studio acceptance first:** visual already accepted (or accepting) via Studio fixture — no promote-before-gallery.
  5. **Not tidiness:** "moves code out of apps/web" alone is **insufficient**.
- **V1.106 invariant**: RF-coupled components are NOT promoted to `@42ch/nexus-ui`.
- **Keep-app-local evidence**: every `web-only wrapper` / `studio-local fixture` decision cites the specific boundary rule (RF-coupled / daemon-coupled / single-consumer / third-surface-not-yet / etc.).
- **No new `{KNOWLEDGE_DIR}/` from this plan** — classification stays in this plan + package AGENTS.md. Knowledge crystallization at Phase 3 `mstar-compound`.
- **Default expectation (architect-locked pre-fill — Execute confirms):**
  - Timeline RF wrappers → `web-only wrapper` (RF-coupled)
  - `@web-canvas/timeline-node-chrome` bodies + `NodeChromeShell` → `studio-local fixture`
  - Layer breadcrumb → `studio-local fixture` (promote-when: third surface)
  - Global Timeline list chrome → `studio-local fixture` (daemon view stays web-only)
  - Conflict-modal chrome → `studio-local fixture`; domain wrappers → `web-only wrapper`
  - Tokens → gallery projection only / N/A promotion
  - **Not** `promoted primitive` unless product criteria § all five bullets pass (unexpected this iteration)
- **`inline` execution endorsed (architect):** docs-only Stretch + single-seat QC + evidence upstream from P0–P2 is appropriate. If Execute finds a genuine package promotion requiring code move, PM opens a thin SDD follow-up — do not expand this plan into package implementation.
