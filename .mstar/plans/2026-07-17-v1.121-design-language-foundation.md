- **Font:** display tier = self-hosted OFL serif, recommended **Source Serif 4** (variable, optical sizing); shortlist Fraunces/Newsreader; subset + `font-display: swap` + preload; fallback stack `Georgia, 'Times New Roman', ui-serif, serif`. If implement measures unacceptable bundle/jank → system-stack fallback + recorded roadmap entry (Durable Roadmap Gate).
  - **Asset location (pinned — concern 1):** canonical provenance `packages/nexus-ui/assets/fonts/` (LFS, OFL license file alongside, matches the existing `packages/nexus-ui/assets/logos/` precedent). - **Ink atmosphere:** dark `background-100…300` + `gray-100…300` get deep-blue cast derived from `brand-deep-blue-1000`; light gets whisper-warm `background-200/300`; full AA table recomputed before lock — any pairing failing AA blocks the value, not the table.

**Decision record (AC-P0-5, 2026-07-17):** **Self-hosted Source Serif 4 ships** — bundle gate PASS, no fallback needed.

- **Family:** Source Serif 4, static weights 400 Regular + 600 Semibold (normal style; no italic, no variable axes).
- **Source / license:** npm `@fontsource/source-serif-4@5.2.9` (pre-subset woff2; upstream Adobe Source Serif 4 via google/fonts); SIL OFL-1.1 — license at `packages/nexus-ui/assets/fonts/source-serif-4/OFL.txt`.
- **Subset params:** fontsource `latin` subset (Latin + common punctuation + figures); unicode-range `U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA, U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122, U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD`.
- **Bundle delta (gate ≤ 80 KB gzipped/weight — PASS):** 400 = 20,088 B raw / 20,154 B gz (~19.7 KiB); 600 = 21,532 B raw / 21,598 B gz (~21.1 KiB). SHA-256 recorded in `packages/nexus-ui/assets/fonts/source-serif-4/README.md`.
- **Layout:** canonical provenance (LFS) + OFL + regeneration README at `packages/nexus-ui/assets/fonts/source-serif-4/`; vendored copies (plain git, `PROVENANCE.md` alongside) at `apps/web/public/fonts/source-serif-4/` + `apps/design-studio/public/fonts/source-serif-4/`; `@font-face` ×2 + `font-display: swap` in `tooling/design-tokens/src/tokens.css`; preload (400 only) in both apps' `index.html`.
- **Fallback stack (runtime):** `--font-display: 'Source Serif 4', Georgia, 'Times New Roman', ui-serif, serif` (Georgia stack serves while woff2 is unavailable; system-stack *replacement* not needed — no V1.122 roadmap entry).
- **Render evidence:** dev-server probe (no markup committed) on studio `/brand` + web `/works` — `document.fonts` both weights `status: loaded`, `fonts.check()` true at 400/600, rendered probe widths differ from Georgia fallback (studio 466≠448 @400, 473≠513 @600; web 466≠448 @400); woff2 served 200 at exact byte sizes on both apps.

## Roadmap

- **CJK serif companion (V1.122 candidate):** the shipped display tier is a Latin-only subset of Source Serif 4 (unicode-range `U+0000-00FF` + Latin-1 supplement). zh-CN content-voice titles (work/world/chapter titles in CJK) fall back to system serif for CJK glyphs — Latin glyphs still render Source Serif 4. The fallback chain (`Georgia → 'Times New Roman' → ui-serif → serif`) is theme-stable but visually different mid-sentence. V1.122 should evaluate a CJK serif companion (e.g. Noto Serif SC subset, OFL) appended to `--font-display`, or accept the system-serif fallback as designed and document it in DESIGN.md §Typography. Trigger: zh-CN authoring dogfood feedback on title rendering; owner: product-manager + architect.
