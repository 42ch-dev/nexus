# P0 — Control Room author-loop dogfood fixes

> **Iteration compass:** `.mstar/iterations/v1.127/delivery-compass.md`
> **Spec:** `.mstar/iterations/v1.127/specs/control-room-author-loop-fixes.md`
> **SSOT status:** `.mstar/status.json`

**Goal:** Pre-empt five manual-test friction points a V1.127 dogfood tester hits in the first 30 minutes on the Control Room + Worlds + Timeline flow: empty Create World click, missing pagination over 20 worlds, silent overview 5xx, selection-submenu popover drift on resize, stale rename input on navigation. Plus close the shipped Setup-Continue hotfix residual as a 5-minute admin task.

**Architecture:** All five fixes are in `apps/web/src/{pages,components}/` — frontend-only, no daemon changes, no schema changes. Each fix is small (10–100 LOC) and scoped to its own file family. Pagination reuses the existing `has_more` + `cursor` composite-endpoint response fields (V1.126 P2). Error banner reuses the existing inline-error pattern. Resize listener is a `useEffect` adding `resize` + `scroll` listeners that call `onClose()`. Stale-state fix is a `useEffect` clearing state on `pathname` change.

**Tech Stack:** React 18 + TypeScript + TanStack Query + React Router + Vitest + Testing Library.

**Execution:** mstar-sdd (multi-task, 6 tasks)
