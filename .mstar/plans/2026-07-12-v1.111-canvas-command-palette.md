## Problem

No command palette exists in the Control Room (grep confirms zero
`CommandPalette`/`cmdk` usage). Authors navigate canvas surfaces and fire
actions purely by pointer. The V1.108/V1.109/V1.110 compasses all name a shared
command palette as the next discoverability feature.

## Scope

Land a keyboard-first command palette (⌘K / Ctrl+K) overlaying the Control Room,
backed by an extensible **action registry** so canvas navigation, node creation,
and surface switching are one keystroke away, and so P1/P2/future surfaces add
commands without editing the palette component.

### Must

- FB-CP-000: ⌘K/Ctrl+K opens palette overlay globally
- FB-CP-001: Action registry feeds palette; fuzzy/substring filter
- FB-CP-002: Full keyboard nav (Arrow/Enter/Escape); focus restoration
- FB-CP-003: Action registry extensible (P1/P2 add commands without editing palette)
- FB-CP-004: Light + dark tokens; a11y (role=dialog, aria-combobox)

## Non-goals

- Editor/format commands; command history; rebindable shortcuts; backend changes.

## Architecture locks (architect — finalized 2026-07-12, code-evidenced)

> Investigated against `apps/web/src/`. Evidence: grep confirms **zero**
> `CommandPalette`/`cmdk` usage and **no fuzzy lib** (`cmdk`/`fuse.js`/
> `fuzzysort`) in any `package.json`. Existing keyboard handling is ad-hoc
> `window.addEventListener('keydown', …)` (5 call sites: `path-context-menu`,
> `chapter-keyboard-nav`, `conflict-modal-base`, `strategy-canvas/canvas-layout`,
> `strategy-canvas/hooks/use-strategy-canvas`) — **no shared `useHotkey` hook
> exists**, so P0 creates one.

1. **Action registry contract** — shape:
   `{ id: string; label: string; group: string; keywords?: string[]; icon?: LucideIcon; handler: () => void; available?: () => boolean }`.
   - **Location:** `apps/web/src/lib/canvas/command-registry.ts` (confirmed —
     the `lib/canvas/` neighborhood already holds canvas data hooks
     `use-strategy-data.ts` / `use-outline-data.ts` / `use-world-kb-data.ts`;
     the registry is canvas-action-scoped this iteration. If non-canvas actions
     are added later, promote to `apps/web/src/lib/command-registry.ts`).
   - **Registration mechanism (extensibility for FB-CP-003):** module-level
     store + `useSyncExternalStore`-backed `useCommands()` selector + a
     `useRegisterCommand(action)` convenience hook. Surfaces call
     `useRegisterCommand({ id, label, … })` in a `useEffect`; the palette
     subscribes via `useCommands()`. This lets P1/P2/future surfaces add
     commands **without editing the palette component** — the core FB-CP-003
     requirement. (Provider/context rejected: it re-renders the whole tree on
     every register; module store + `useSyncExternalStore` is cheaper and
     decoupled.)
2. **Filter** — case-insensitive substring match across `label` + `keywords`,
     with a cheap relevance rank: exact-label → label-startswith →
     label-contains → keyword-contains. **No new fuzzy dep** (none exists in
     the workspace; substring+rank satisfies FB-CP-001). fzf-style subsequence
     ranking deferred to next iteration.
3. **Hotkey** — new thin hook `apps/web/src/lib/use-hotkey.ts`:
   `useHotkey(key: string, handler: (e: KeyboardEvent) => void, opts?: { preventDefault?: boolean })`.
   ⌘K/Ctrl+K registered in `root-layout.tsx` (impact-checked: `RootLayout` is
   consumed only by `AppRoutes` — LOW risk; mounting the palette is additive).
   **Conflict-avoidance:** the hook ignores activation when
   `document.activeElement` is `INPUT`, `TEXTAREA`, `[contenteditable]`, or
   within `[data-command-palette-ignore]` / a React Flow editor pane
   (`.react-flow`). ⌘K still fires from buttons/links/canvas background so the
   palette is globally reachable.
4. **Palette component** — `apps/web/src/components/command-palette.tsx`
   (**top-level `components/`, NOT `components/canvas/`** — the palette is a
   global shell overlay mounted in `root-layout.tsx`, not a canvas surface;
   placing it under `canvas/` would mislabel it). role=dialog + combobox +
   listbox/option; focus trap; restore focus to caller on close. Mounted once
   in `RootLayout`.
5. **Token consumption** — reuse DESIGN.md overlay/elevation/`gray-alpha-*`
   tokens. No new tokens expected; if the palette needs an overlay-elevation
   token not in DESIGN.md, add it to DESIGN.md + DESIGN.dark.md + tokens.css
   in the same commit.

- Tests: command registration + handler invocation (mocked router/selection).

  needed, add to DESIGN.md + DESIGN.dark.md + tokens.css in the same commit.
- No Studio fixture mirror (P2 owns its own fixtures; Studio canvas gallery
  already exists).
