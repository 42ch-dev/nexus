# P1: Rust Dependency Lockfile Refresh + cargo-audit Baseline

## 1. Problem

`Cargo.lock` carries ≈182 stale patch/minor versions (last meaningful refresh around V1.158). Stale transitive deps delay upstream bugfixes and add noise to future `cargo audit` / Dependabot runs. Frontend lockfile is almost current; only `oxlint` 1.75→1.78 is pending as a mechanical bump.

## 2. Goal / value

- Refresh the Rust lockfile **within existing `Cargo.toml` ranges** (lockfile-only).
- Prove the tree still builds, tests, lints, and formats clean.
- Record a dated `cargo audit` baseline for the libp2p-blocked advisories.
- Land the pending `oxlint` lockfile bump with web tests green.

Maps to compass AC-1..AC-4.

| ID | Criterion | Evidence |
|----|-----------|----------|
| **AC-P1-1** | `cargo update` applied workspace-wide; `Cargo.lock` diff is non-empty (or dry-run proved already current — then note “0 pending” and still run gates) | `Cargo.lock` diff / dry-run log in task report |
| **AC-P1-2** | No intentional `Cargo.toml` version-range or pin edits; spoke `=0.9.2` and libp2p `=0.56.0` pins unchanged | `git diff -- Cargo.toml '**/Cargo.toml'` empty (except if an emergency `--precise` pin-back is documented) |

| **AC-P1-6** | `wire_contracts_changed: false` — no schema/daemon/API surface edits | `git diff` scoped to lockfiles (+ optional pin-back note) |

## 4. Non-goals (this plan)

- Manifest major upgrades or range widenings.
- libp2p / yamux / hickory forced upgrades; spoke pin bump.
- `.github/workflows/**` edits.
- Product residual implementation (run_checker, AC-I5, spoke_rules, flakes).
- Residual archival / `tech_debt_summary` rewrite (P2 owns ledger).

## 5. Technical design

### T1 — `cargo update` + verification

Run workspace `cargo update` (respects existing ranges). Then:

1. `cargo build --workspace`
2. `SQLX_OFFLINE=true cargo test --workspace`
3. `SQLX_OFFLINE=true cargo clippy --all-targets -- -D warnings`
4. `cargo +nightly fmt --all -- --check`

**Breakage policy:** identify crate → `cargo update -p <crate> --precise <previous>` → document in commit body. **Do not** edit version ranges to “make it pass.”

### T2 — oxlint + cargo-audit baseline

1. `pnpm update oxlint` (lockfile-only expected).
2. `cd apps/web && pnpm test -- --run`.
3. `cargo audit` (install `cargo-audit` if missing) → save summary for report/commit.
4. Cross-check advisories against open residuals `R1`/`R2` (P2 will stamp freshness notes; P1 only needs the audit artifact).

## 6. Tasks

### T1: cargo update + build/test/clippy/fmt verification

**In scope files:** `Cargo.lock` (only; emergency pin-back still lockfile-only unless impossible — then STOP).

**Out of scope:** any `Cargo.toml`, workflows, app source, `status.json`.

**Commands:**

```bash
cargo update
CARGO_TARGET_DIR=$HOME/.cache/nexus-target SQLX_OFFLINE=true cargo build --workspace
CARGO_TARGET_DIR=$HOME/.cache/nexus-target SQLX_OFFLINE=true cargo test --workspace
CARGO_TARGET_DIR=$HOME/.cache/nexus-target SQLX_OFFLINE=true cargo clippy --all-targets -- -D warnings
cargo +nightly fmt --all -- --check
```

**STOP if:**

- Fixing a break requires editing `Cargo.toml` ranges or bumping spoke/libp2p.
- Failures are unrelated massive pre-existing breakage on `main` (escalate; do not “fix product” in this plan).

**Done when:** AC-P1-1..3 hold; report notes any `--precise` pin-backs.

### T2: oxlint bump + cargo-audit baseline

**In scope files:** `pnpm-lock.yaml` (oxlint); audit log artifact under task report (not product source).

**Out of scope:** app TS/Rust source, residual archival, Dependabot config.

**Commands:**

```bash
pnpm update oxlint
cd apps/web && pnpm test -- --run
cargo install cargo-audit 2>/dev/null || true
cargo audit 2>&1 | tee /tmp/cargo-audit-v1.161.txt
```

**STOP if:** oxlint bump forces unrelated major frontend upgrades or widespread test failure not resolved by lockfile-only rollback of oxlint.

**Done when:** AC-P1-4..6 hold; audit summary attached to `.mstar/sdd/2026-08-12-v1.161-p1-rust-dependency-refresh/task-2-report.md` (and T1 report for T1).

## 7. Global Constraints

- **Lockfile-only** Rust changes — no `Cargo.toml` manifest version-range changes.
- `SQLX_OFFLINE=true` for all cargo build/test/clippy commands.
- `CARGO_TARGET_DIR=$HOME/.cache/nexus-target`.
- If a dep update breaks, pin back and document — **do not** change version ranges.
- **Do not** bump spoke (`=0.9.2`) or libp2p (`=0.56.0`).
- **Findings cleanup:** `zero-residual` for issues introduced by this plan.
