## Architecture lock

- **Ownership:** `SidecarManager` owns the complete restart transaction and a single-flight mutex. Concurrent clicks join/reject the in-flight operation; they never run overlapping stop/start sequences.
- **Owned daemon:** terminate through the retained child handle, wait for process exit and `PortState::Free`, then spawn the bundled sidecar and wait for health.
- **Attached daemon:** require successful Nexus health plus stable listener PID/process identity before signaling it. Re-check the same PID before signal; foreign or unverifiable listeners are reported as conflicts and are never killed. After spawn, the replacement is `owned=true`, so every later Restart follows the owned path.
- **State model:** transition once into restarting/starting, emit status immediately, clear stale child/version state, and finish only at healthy `Running` or actionable `Error`. Monitor-driven crash restart must not race the user restart.
- **Boundary:** expose one Tauri `restart_daemon` command and one `DesktopCapabilities.restartDaemon()` method. Footer UX calls only that method and renders pending/failure inline.
- **Wire:** `wire_contracts_changed: false`; this is desktop-native IPC/process control.
