## Problem

After P0, most product surfaces still hardcode English. Iteration acceptance
requires **all user-facing** `apps/web` copy to go through i18n, with
`format.ts` / `Intl` following the active locale.

## User value

An author who sets Language to 简体中文 sees the **entire** Control Room product
experience — not just shell chrome — in Chinese, including dates, numbers, and
command labels, with no page reload when switching back to English.

## Scope

Migrate remaining user-facing strings across product surfaces; expand catalogs;
ensure date/number/relative-time helpers use the active locale; leave a clear
Done audit (no leftover hardcoded user-facing product copy).

### Must

- FB-MIG-000: Setup wizard + first-launch chrome via `t()`
- FB-MIG-001: Canvas surfaces + inspectors + command palette labels via `t()`
- FB-MIG-002: Reading / findings / memory / soul / chapters chrome via `t()`
- FB-MIG-003: Toasts, empty states, error helpers that are user-facing via `t()`
- FB-MIG-004: `format.ts` and related `Intl` call sites use active locale
- FB-MIG-005: Migration audit gate (grep / checklist) — no leftover user-facing
  hardcoded product copy in production UI modules

**User-facing (in scope):** labels, buttons, nav, dialogs, placeholders,
empty states, toasts, and error messages shown to authors in `apps/web/src`.
**Out of scope:** manuscript/author content, test fixtures,
developer-auxiliary surfaces (including `apps/design-studio`), `console.*` /
dev-only strings, `@42ch/nexus-ui` default slot text (callers supply `t()`
output).

### Done (P1)

- Audit evidence attached to plan QC (grep pattern + manual spot-check list).

### 2. Command registry — instant switch (locked pattern)

**Problem:** `useRegisterCommand` captures the `Command` object once per mount
(keyed by `id` only). Storing resolved English `label` strings prevents instant
switch without re-registering every command on locale change.

**Selected approach: translation keys + palette render-time resolution**

1. **Extend `Command` interface** (`lib/canvas/command-registry.ts`):

```typescript
readonly labelKey: string;
readonly labelNs?: string;        // default 'commands'
readonly groupKey: string;
readonly groupNs?: string;        // default 'commands'
readonly keywordKeys?: readonly string[];
readonly keywordNs?: string;      // default 'commands'
// REMOVE readonly label / group / keywords string fields
```

2. **Resolve in `command-palette.tsx`** (and any test helpers that assert labels):
   - `useTranslation()` subscribes to language changes → palette re-renders.
   - `useMemo` map: `commands.map(c => ({ ...c, label: t(c.labelKey, { ns }), group: t(c.groupKey, { ns }), keywords: … }))`.
   - Pass **resolved** commands to `filterCommands` (ranking uses localized labels).

3. **Registrants** pass stable keys, e.g. `labelKey: 'go.strategy.label'`,
   `groupKey: 'group.navigate'` in `commands.json` for both locales.

4. **Do not** add `i18n.language` to `useRegisterCommand` effect deps (avoids
   store churn). Handlers keep the existing **ref pattern** for live navigation
   (`canvas-nav-commands.tsx`); only display fields move to keys.

5. **Tests:** update `command-registry.test.ts` fixtures to use keys; add palette
   test that switches locale and asserts label text changes without remount.

### 3. format.ts / Intl — active locale wiring

**File:** `apps/web/src/lib/i18n/active-locale.ts` (created in P0) exports
`getActiveLocale(): ResolvedLocale`.

**Changes to `lib/format.ts`:**

| Function | Change |
|----------|--------|
| `formatDateTime`, `formatDate` | `Intl.DateTimeFormat(getActiveLocale(), …)` instead of `undefined` |
| `formatUtcAndLocal` | `utc` keeps `'en-US'` + `timeZone: 'UTC'`; `local` uses `getActiveLocale()` |
| `formatRelative` | Prefer `Intl.RelativeTimeFormat(getActiveLocale(), { numeric: 'auto' })` with unit selection; fallback strings (`just now`, `m ago`) move to `common.json` if any manual fragments remain |
| `humanizeStatus` | User-facing status badges → `t()` in callers or a small `common.status.*` key map (do not English-title-case in helper for zh-CN) |

**Call-site rule:** production UI must not pass `undefined` locale to `Intl.*`.
Tests may stub `getActiveLocale` or wrap `LocaleProvider`.
