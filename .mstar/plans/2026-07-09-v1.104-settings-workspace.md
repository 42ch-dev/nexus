# P0 — Settings Workspace Path (W2)

**Phase 1:** architect-locked (§5.2); writing-polished (§5.3)  
**Goal:** Authors can view and change the active workspace folder from Settings, with honest restart/reload guidance after persist.

**Architecture:** Add `/settings/workspace` under the existing Settings shell; mount `SettingsWorkspaceSection`; reuse `useDesktopCapabilities()` methods (`getWorkspaceRoot` / `pickDirectory` / `setWorkspacePath`) with Tauri invoke parity to `setup-step-welcome.tsx`. Post-persist copy-only honesty — no automatic daemon restart. Browser: `desktop === null` branch mirrors `settings-setup-section.tsx`.

4. Browser: honest desktop-only disabled state (no fake HTTP path API).

6. Prefer no `schemas/` change.
