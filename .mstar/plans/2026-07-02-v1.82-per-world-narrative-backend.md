## 1. Problem statement

V1.81's `/soul/reflect` is Creator-level (world-agnostic). V1.82 extends it to
per-World: an optional `world_id` scopes the synthesis + cache + stats to a
world's fragment subset, with ownership enforced.

## 2. Scope

### 2.A Composite-key cache migration + DAO signatures

**Migration** (`crates/nexus-local-db/migrations/20260704_000001_memory_soul_narratives_composite_world_key.sql`):

The exact DDL is locked in P-1 §2.4.2 (reproduced there). Implement verbatim:
recreate `memory_soul_narratives` with `PRIMARY KEY (creator_id, world_id)` +
**partial UNIQUE index** `idx_memory_soul_narratives_creator_only ON
(creator_id) WHERE world_id IS NULL` (SQLite NULL-in-composite-PK mitigation) +
**by-name column-list** copy (existing rows → `world_id = NULL` Creator-level).
This is additive-compatible: every V1.81 Creator-level row survives as the
`(creator_id, NULL)` row.

**DAO signatures** (`crates/nexus-local-db/src/soul_narrative.rs`) — all gain an
`Option<&str> world_id` parameter; `None` = Creator-level narrative (the whole), `Some(w)` =
that world's per-World narrative:

| Function | Current | V1.82 | Notes |
|---|---|---|---|
| `get_soul_narrative` | `(pool, creator_id)` | `(pool, creator_id, world_id: Option<&str>)` | WHERE uses `creator_id = ? AND world_id IS ?` (SQLite `IS` matches bound NULL → NULL row). Returns the `(creator, world)` cache row. |
| `SoulNarrativeRecord` | `creator_id` only | add `world_id: Option<String>` | Persisted as the composite-PK pair. |
| `upsert_soul_narrative` | `(pool, record)` | unchanged signature; SQL adds `world_id` to the INSERT column list + bind | `INSERT OR REPLACE` conflict target = the composite PK (world-bearing) or the partial UNIQUE index (Creator-level NULL). |
| `soul_narrative_fragment_stats` | `(pool, creator_id)` | `(pool, creator_id, world_id: Option<&str>)` | All three aggregates (`COUNT`, `MAX`, distinct-keyword stream) gain the world filter: `Some(w)` → `AND world_id = ?`; `None` → no filter (the whole). |
| `compute_distinct_keyword_count` | `(pool, creator_id)` | `(pool, creator_id, world_id: Option<&str>)` | early-exit stream adds `AND world_id = ?` when `Some`. |
| `update_stats_cache` | `(pool, creator_id, …)` | add `world_id: Option<&str>` | INSERT/UPDATE target the `(creator, world)` row. |
| `build_stats_fingerprint` | pure `(count, max)` | **unchanged** | Per-scope fingerprint formula is identical; the scope enters via the per-(creator,world) aggregates. |

**Fingerprint cache key per (creator, world)**: the cache row lives at
`(creator_id, world_id)` on `memory_soul_narratives`; the fingerprint is
`"{fragment_count}:{max_created_at}"` computed over that scope's fragments. The
read-path early-exit (fingerprint match → return cached count, no keyword scan)
applies per scope. No new index (the existing `idx_memory_fragments_creator_world_created`
serves all per-World aggregates — see P-1 §2.4.3).

### 2.B Endpoint extension (`crates/nexus-daemon-runtime/src/api/handlers/memory.rs::reflect_soul`)

Read the optional `world_id` from the (P-1) `SoulNarrativeRequest`. The
extension is surgical on the existing V1.81 control flow:

**B.1 Ownership check (only when `world_id` is `Some`)** — reuse the existing
`nexus_local_db::narrative_write::is_world_owned(pool, creator_id, world_id)`
helper (`crates/nexus-local-db/src/narrative_write.rs:265`), which queries
`SELECT world_id FROM narrative_worlds WHERE world_id = ? AND owner_creator_id = ?`
— the same `owner_creator_id` column used by the works/world_kb/host-tool
handlers. Insert immediately after the `creator_id` validity check and **before**
any stats/synthesis work:

```rust
let world_id = req.world_id.as_deref();  // None = Creator-level
if let Some(w) = world_id {
    if !nexus_local_db::narrative_write::is_world_owned(state.pool(), &active_creator, w)
        .await
        .map_err(|e| NexusApiError::Internal { code: "DATABASE_ERROR".into(), message: e.to_string() })?
    {
        return Err(NexusApiError::Forbidden {
            resource: "soul_narrative".into(),
            reason: format!("creator does not own world '{w}'"),
        });
    }
}
```

**Rejection code**: `NexusApiError::Forbidden` (403) — consistent with the
existing active-creator mismatch already in `reflect_soul` (line ~1131) and the
`NexusApiError` single-source envelope rule. A world-scoped narrative cannot
leak across creators: a non-owned `world_id` (whether non-existent or owned by
another) is rejected before any stats query or synthesis.

**B.2 Stats / cache / gate (per scope)** — pass `world_id` through to every DAO
call: `soul_narrative_fragment_stats(pool, &active_creator, world_id)`,
`get_soul_narrative(pool, &active_creator, world_id)`,
`upsert_soul_narrative(pool, &record_with_world_id)`. The insufficient-data gate
(`fragment_count < MIN_SOUL_NARRATIVE_FRAGMENTS || distinct_keywords < MIN_…`)
applies **per world** — a world may be below-gate even when the Creator whole is
above. The `SoulNarrativeResponse` shape is unchanged; the same state enum is
returned scoped to the (creator, world) pair.

**B.3 Read-path state enum — greploop lesson (mandatory, no LLM on `force=false`)**:

The V1.81 control flow (`on-demand-synthesis-read-path-invariant.md`) extends
verbatim to the world scope. With a world present, `force=false` MUST return one
of these states **without invoking the LLM**:

```
if below per-world gate                 → state: "insufficient_data"   (no LLM)
if !force (per-world):
    cached + has-narrative + !stale     → state: "current"             (no LLM)
    cached + has-narrative + stale      → state: "stale"               (no LLM)
    stats-only row (narrative=None)     → state: "ungenerated"         (no LLM)
    else (no cache row)                 → state: "ungenerated"         (no LLM)   ← the branch V1.81 missed
// ONLY reached when force == true
synthesize over the world subset → persist (creator, world) → state: "current"
```

**Negative-path regression test (mandatory)**: `force_regenerate=false` + an
**owned** world + above-gate + no cache row → response `state == "ungenerated"`
and **the capability registry is never consulted** (in test mode the registry is
`None`; the read path must succeed returning `ungenerated`, NOT error with
"capability registry not available"). A companion `force_regenerate=true` test
asserts the synth path IS reached (returns `ServiceUnavailable` in test mode,
proving the gating asymmetry). This is the portable guard from the greploop
lesson, applied per world.

**B.4 Synthesis input (only `force=true`)** — `build_soul_narrative_synthesis_input`
gains the world filter; the synthesis input is **the world's fragment subset**
(`WHERE creator_id = ? AND world_id = ?`), capped (reuse the V1.81 input cap on
the subset). Temporal buckets remain chronological (the V1.81 greploop
chronological-order fix applies unchanged — order by `created_at ASC` within the
subset). The synthesizer is the same `AcpSoulNarrativeSynthesizer`; only the
input slice + cache row differ.

- **`nexus-local-db`**: new migration + `soul_narrative.rs` signature changes.
  `narrative_write::is_world_owned` is already public + already consumed by
  `nexus-daemon-runtime` (host-tool handlers) — no new export needed.

  unchanged; P0 does not extend the gateway).
- **`nexus-contracts`**: only the P-1 codegen output (regenerated); P0 consumes
  the frozen `SoulNarrativeRequest` with optional `world_id`.
