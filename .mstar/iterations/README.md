# Iterations

Iteration-level packages for Nexus delivery tracks. Each `<iteration-id>/` directory holds the delivery compass, optional `guides/`, and optional `specs/`.

**Canonical layout** (per `mstar-iteration` artifact boundaries):

```text
.mstar/iterations/
  README.md                 # one row per iteration → <iteration-id>/
  <iteration-id>/
    delivery-compass.md     # iteration SSOT (frontmatter status)
    README.md               # optional package index
    guides/
    specs/
```

Implementation-detail SSOT that is not iteration-scoped stays in [`.mstar/knowledge/`](../knowledge/README.md).
