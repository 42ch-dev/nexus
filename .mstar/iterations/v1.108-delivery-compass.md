## Product Story

**Who:** Authors steering Works via Outline/Strategy/World KB canvases; contributors iterating chrome in Design Studio.

**Problem:** Outline remains panel+inspector while Strategy/World KB ship React Flow — authors cannot “shape outline/timeline spatially” as promised in `canvas-strategy-surface.md` / V1.72. Separately, Settings Studio fixtures still ship a stale shell (underline tabs, plain nav, text profiles) and AgentPicker status/hover/custom-launch UX mislead.

**Narrative:** Deliver Outline spatial parity on existing patch routes (prefer no wire change), while unifying shell/AgentPicker chrome under studio-first so Canvas IA and Settings Surfaces stop drifting.

**Iteration complete when:** Both Must plans Done (or non-blocking residuals documented); P0 FB-C1-000..006 accepted in App; P1 FB-UI-001..010 Studio-accepted (visual FBs) then App parity where applicable.
