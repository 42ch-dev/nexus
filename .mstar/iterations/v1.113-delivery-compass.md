# V1.113 Delivery Compass - i18n Completion + UI Normalization + Tech Debt

## Product story (why authors care)

V1.112 shipped the i18n **foundation** and migrated primary shell/canvas/settings
surfaces. Authors who choose **zh-CN** still hit English on the Control Room
list and detail pages (Works, Schedule, Sessions, Strategies, Capabilities) and
two common dialogs — a half-finished localization experience.

This iteration finishes the author-facing language story for en/zh-CN:

1. **Speak the author's language end-to-end** on Control Room product pages
   (not just chrome).
2. **Trust the UI** — disabled and listbox states use shared design tokens so
   light/dark and future theme work stay consistent.
3. **Keep the slate honest** — fix design-studio test noise and pay down a
   bounded set of residuals so the next feature iteration starts clean.

This is a **product-completeness** iteration (finish what V1.112 started), not
a new author loop or canvas feature.

## Scope

**Direction lock mode: autonomous** (code-first research → ranked candidates → locked).

Equip `apps/web` with complete **Control Room product-page** i18n coverage by
migrating remaining ~110 hardcoded user-facing strings across 9 page/dialog
files, fix catalog hygiene (duplicate keys, uncached formatters, runtime guard),
normalize UI tokens (DESIGN.md gaps + disabled-state `opacity-50` sweep), and
pay down targeted tech debt from `status.json` residuals.

1. **P0 - i18n Completion (Must):** Migrate hardcoded user-facing strings in
   Works, Schedule, Sessions, Strategies, Capabilities, Work Detail, and
   Strategy pages + Patch Work / Validate Preset dialogs. Fix catalog duplicate
   keys (R-P0-002), add `setPreference` runtime guard (R-P0-004), cache Intl
   formatters (R-P1-002). Close R-P0-005 (not-found keys are used — not a bug).
2. **P1 - UI Normalization (Must):** Add missing DESIGN.md tokens
   (`sidebar-nav.disabled*`, `listbox.maxHeight`, shared `disabled.opacity`) and
   sweep **disabled-state** inline `opacity-50` usages to the shared token.
   DESIGN.md and DESIGN.dark.md are at repo root. Close R-V1111P3QC1-S001.
3. **P2 - Tech Debt Paydown (Should):** Fix design-studio pre-existing test
   failures (R-P0-006, ~7 per status.json), close ≥10 older low/nit residuals
   (or accept with rationale), update `status.json` for V1.112 ship + refresh
   `tech_debt_summary`, and update deferred-features tracker quick-status line.
   **Depends on P0** (design-studio failures are i18n-adjacent; residual
   selection benefits from P0 catalog work being done).
