## 2.1 Architecture Hierarchy and Ownership

- **P0 lives in `packages/nexus-ui/`**: `src/components/nexus-logo.tsx`, `src/tokens.ts`, component tests. Pure TypeScript refactor; no build/export change.
- **P1 lives in `crates/nexus-daemon-runtime/src/api/`**: `handlers/host_tool_handlers.rs`, `handlers/outline.rs`, `handlers/chapters.rs`, `path_guard.rs` (receives the extracted `resolve_guarded_path_async` wrapper from `host_tool_handlers.rs:773`), `auth_middleware.rs`, `mod.rs`. No schema or Local API shape change.
- **`resolve_guarded_path_async` visibility**: The existing async wrapper is a private `async fn` in `host_tool_handlers.rs:773` that wraps the sync `resolve_guarded_path` via `tokio::task::spawn_blocking`. For T3 to migrate `outline.rs` and `chapters.rs` call sites, it must be extracted to `path_guard.rs` as a `pub` function. The sync `resolve_guarded_path` in `path_guard.rs` remains the canonical implementation — it is NOT being removed or changed. Note: the async wrapper takes owned `PathBuf` + `String` (for the `spawn_blocking` closure), so call sites must convert `&Path` → `PathBuf` and `&str` → `String` at each migration point.
- **Tracker cleanup lives in `.mstar/knowledge/`**: `deferred-features-cross-version-tracker.md` and `archived/shipped-features-tracker.md`.
- **Spec owner**: `@architect` reviews the reliability changes during Prepare (Phase 1 Review & Edit chain).
