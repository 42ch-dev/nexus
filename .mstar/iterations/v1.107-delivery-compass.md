## Product Story

**Who:** Authors using first-launch / Settings / Control Room, plus contributors iterating UI in Design Studio.

**Problem:** V1.106 shipped the studio-first pipeline and claimed Badge/Select/AgentPicker polish, but Design Studio still fails visually for many matrices (missing Tailwind content scan → invisible destructive/solid fills; cramped wizard IA) and App has not adopted package Toast. Studio `AppShellFixture` and `settings-host-fixtures` duplicate or stub App chrome — so contributors cannot trust Studio as SSOT.

**Narrative:** Fix the Studio paint pipeline first, land visual FBs against Studio matrices, then close coverage gaps so Studio remains the authoritative preview surface for author-facing chrome.

**Iteration complete when:** P0 automated gates pass for FB-000..016 (or documented deferrals with residual rows for non-blocking backlog items under 016 only).
