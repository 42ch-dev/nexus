This foundation-finishing step ensures future brand-token changes propagate predictably and the UI feels trustworthy for extended creative sessions — it is the durable token completion of the brand layer before any primitive extraction or next feature loop. No new author-facing features, no wire/schema/contract changes, no new `@42ch/nexus-ui` export surface.

## 2.1 Architecture Hierarchy and Ownership

V1.84 preserves the V1.83 hierarchy: root `DESIGN.md` / `DESIGN.dark.md` → `@42ch/nexus-ui` package exports → `apps/web/DESIGN*.md` consumption mapping → `apps/web` implementation. No layer is added or moved.

- **P0** owns `apps/web/src/index.css` token consolidation **only** (verified single-file change set: 6 solid-hex literals → `var(--color-blue-700)`, 5 rgba tints → `color-mix`). The `apps/web/src/components/canvas/**` and canvas-page TSX are verified clean (V1.83 retinted them) and are explicitly out of P0's edit surface. P0 must not edit root `DESIGN*.md` / `apps/web/DESIGN*.md` brand values (the SSOTs), `packages/nexus-ui/**`, nor `apps/web/src/test/setup.ts` (P1-owned).
- **P1** owns `.github/workflows/**` (CI checkout LFS for `web-build`/`desktop-build.yml` ×2 + new `nexus-ui` job in ci.yml) and the Vitest localStorage-warning suppression in `apps/web/vitest.config.ts` **and** `apps/web/src/test/setup.ts` (test-infra carve-out). It must not touch `apps/web/src/index.css` or any other `apps/web/src/**` component/CSS logic.
- **Cross-plan isolation:** P0 (`apps/web/src/index.css`) and P1 (`.github/workflows/**` + `apps/web/vitest.config.ts` + `apps/web/src/test/setup.ts`) have non-overlapping file sets, so they may run on parallel branches without conflict. The only P1 file under P0's nominal `apps/web/src/**` tree is `apps/web/src/test/setup.ts` — explicitly carved out as P1-owned test infra. No shared workspace file (root `package.json`, `pnpm-workspace.yaml`, `pnpm-lock.yaml`) is edited by either (no dependency changes); the only shared surface is the integration branch itself at merge time.
- **DESIGN.md discipline:** if P0 discovers a token gap (a needed brand value missing from root DESIGN), it reports it rather than fabricating a value; the root DESIGN is amended first if genuinely required.
